# 设计与首版范围

面向 Max 的本地光场实验台。单一任务：在硬件到货前备好正确的多视图内容，到货后完成可记录的光学验证。

配色：雾蓝 #e8eef1、瓷白 #fbfcfd、石墨 #243440、深青 #23877f、陶土 #dd9678。中文标题用系统苹方，正文系统 sans-serif，仪器读数用等宽字体。主视觉是一块按真实 9:16 比例呈现的小窗；水平观察位置滑轨与它直接相连。控制位于一旁，用户先看见空间，再调深度与内容。

不做宣传站或数据看板。审阅后去掉装饰性统计卡、自动旋转、虚构的设备在线状态；不让旋转动画冒充观看位置变化。默认场景静止，滑轨改变相机。真实光场模式只在导入设备参数且全屏像素匹配后输出。

v0：标准遮挡场景 / 自包含 GLB 导入 / 单视角预览 / 8×5 Quilt 预览与 4320×4800 PNG 导出 / 校准文件导入 / 受尺寸检查保护的实验接屏 / 人工验收记录导出。

下一阶段：一份真实 UNSEEN 静态场景。3DGS、多图重建和语音内容只在首个光学测试通过后接入；本版不声称能读取 3DGS 或把普通照片变成真实完整空间。
