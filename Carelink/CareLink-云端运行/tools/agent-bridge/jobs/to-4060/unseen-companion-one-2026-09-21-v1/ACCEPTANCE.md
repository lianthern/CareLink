# 验收与回报

| 阶段 | 所需证据 | 允许的结论 |
|---|---|---|
| 收件 | 控制包、运行包的真实下载校验；机器名、tag/commit、SHA | RECEIVED_VERIFIED，仅收件 |
| Windows 可运行 | 原生 Windows 实际启动，页面/GLB/Quilt/错误参数/重启检查，浏览器与 GPU 版本 | WINDOWS_SOFTWARE_READY |
| UNSEEN 内容接入 | 一份本机真实 3D 场景的来源和 hash、相机约定、40 视图导出及可复现命令；深度/视序检查 | REAL_SCENE_QUILT_READY |
| 无硬件阶段完成 | 上面所有独立软件项完成，一页接线/校准步骤、可运行版本、未过项 | READY_FOR_HARDWARE，不等于硬件完成 |
| 光学实测 | 官方样例正常；设备固定、人左右移动看到不同遮挡；前后深度正确；记录重影/观看距离/范围；Max 实际观察 | HARDWARE_VALIDATED；全项达到后才能 COMPLETED |

每条测试记录应说明真实输入、代码版本、命令、输出位置/哈希、结果及未覆盖项。实际帧率/渲染耗时只填写测到的值，不在没有 Windows/硬件证据时填写估计成功。

优先静态 / 离线 Quilt。第一版无需实时 40 相机、高质量新训练、全房间走动或语音聊天。不得用同一张图片复制 40 格或物体自转冒充真实视点；0% 深度模式只用作明确标注的平面基线。

屏幕未到时，不等待校准文件才启动软件或真实场景工作。软件已全部就绪但只有硬件门未过时，一次报告该等待条件和接屏动作即可；不要制造重复任务、定时空转或假完成回执。

回传报告至少回答：Windows 能否一键启动；这版修了什么；用了哪个真实 UNSEEN 场景；Quilt 格式和相机约定；已经过的测试；当前最快的接屏方式；到货后还需要什么；有无与旧工作冲突。保留源代码、失败证据与旧包。
