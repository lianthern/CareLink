# 回见设计说明

这份文档给继续改产品与美术的队友使用。当前版本的核心不是“做一本复杂纪念册”，而是把一张照片交给一个会看图、懂得停下来的小伙伴。

## 产品与角色

- 产品名：**回见**
- 照片伙伴：**阿见**
- 一句话体验：**先证明自己真的看见了，再问照片没有拍下来的事。**

阿见不是日记作者，也不是问卷主持人。它只做三件事：

1. 说出一到两条确定可见的画面事实；
2. 每次只问一个画面外的问题；
3. 把照片和用户原话原样放成一页。

不猜身份、关系、年龄、情绪或敏感属性；看不清就直接说“不猜”。

## 阿见的造型

阿见是一张“会折角的小相片”，不是动物或真人 IP。

- 竖向圆角相纸，右下角有一个可开合折角；
- 两枚石墨色小圆点作眼睛；
- 没有嘴、手、服装或夸张表情；
- 始终和用户照片物理相连，从照片下沿或一角探出；
- 在 24px 和单色打印时仍应靠轮廓、折角和双眼被识别。

可以改材质、比例、眼神和折角动画，但不要把它改成悬空客服头像。

## 五种状态

实现中的状态名固定为：

| 状态 | 含义 | 视觉动作 |
| --- | --- | --- |
| `entering` | 阿见第一次出现 | 折角轻开合一次 |
| `seeing` | 正在看照片 | 眼睛横向扫一次，随后静止 |
| `thinking` | 根据用户回答找下一问 | 身体轻微倾斜，折角慢抬 |
| `asking` | 已准备好一个问题 | 站在照片说明条旁，保持安静 |
| `closing` | 把照片与原话放成一页 | 折角展开成分隔线，随后静止 |

动画只表达状态变化，不循环卖萌；`prefers-reduced-motion` 下必须保持完整可用。

## 页面节奏

### 首屏

只保留阿见的自我介绍、一个“选一张照片”主按钮、一个“先试一张”次入口和清楚的隐私说明。

### 看图与对话

- 照片固定在上方；
- “我看到了”接在照片下沿，不做左右聊天气泡；
- 当前只展示一个问题；
- 默认两轮后停下来，让用户选择“再补一句”或“就这样留下”；
- 第三轮必须由用户主动进入；
- 第一轮回答后即可提前结束。

### 成页

最终页保留原图和用户原话，不自动润色。允许返回修改原话，支持浏览器打印或存 PDF。

## 视觉令牌

主要令牌在 `public/style.css` 顶部，队友应优先修改变量，不要在组件里散落新颜色。

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `--night-blue` | `#142536` | 全局背景与深色文字 |
| `--photo-paper` | `#FFF9EA` | 相纸、输入区、结果页 |
| `--shutter-blue` | `#8BC4DE` | 主按钮、焦点环、折角 |
| `--string-light` | `#F2C55C` | 看图状态与少量提示 |
| `--memory-red` | `#B64942` | 日期戳与错误 |
| `--graphite` | `#26333D` | 正文与眼睛 |

正文至少 18px，问题至少 22px，触控目标至少 48px；正文对比度至少 4.5:1。

## 美术改造入口

- 角色结构：`public/index.html` 中的 `.agent`；
- 角色五态：`public/style.css` 中 `.agent.entering / seeing / thinking / asking / closing`；
- 品牌小图标：`public/icon.svg`；
- PWA 图标与主题：`public/manifest.json`；
- 对话和状态切换：`public/app.js` 的 `setAgentState`。

建议先改 CSS 与 SVG，不改 API 合同。任何新造型都要完整走一遍：首屏 → 看图 → 两轮停下 → 主动第三轮 → 成页 → 打印。

## 不在这版做

- 登录、数据库、社区、回忆墙；
- 多人协作或真实印刷下单；
- 自动写抒情长文；
- 人脸识别、关系猜测和情绪判断；
- 为了展示技术而增加 3D、粒子或复杂编辑器。
