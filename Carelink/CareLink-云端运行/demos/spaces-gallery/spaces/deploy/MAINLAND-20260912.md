# 国内慢网优化 · 2026-09-12

Max 确认访问人群主要在国内、朋友卡在模型下载、域名尚未备案。本次优化的是静态空间合集，不是 UNSEEN App 的账号/照片后台。

## 已上线的行为

- CDN 入口：[所有空间](https://spaces.maxxam.xyz/spaces/)。EdgeOne 复用现有境外个人套餐，源站仍为原有香港服务器；未购买、升级套餐或开启中国大陆节点。
- 原有 [备用入口](https://maxxam.xyz/spaces-preview/) 也使用 v2，继续直连香港源站。原 GitHub Pages 保持原版本。
- 8 组空间、14 个 SOG：先加载 75,000 splat、0 阶球谐的轻量预览，等待排序和实际渲染后开放漫游，再后台加载原始完整模型。更换模型不重新设定相机、照片锚点或碰撞。
- 每个预览 922,907–973,845 字节；原模型 8,026,873–19,429,922 字节。首次模型下载量减少 87.9%–95.2%。完整源模型/照片 32 个 SHA256 全部不变；新增预览会使一次完整访问额外传输约 1 MB，长期缓存生效后可复用。
- 完整模型失败时继续保留可行走预览，并提供重试；预览失败则回退原模型。`?quality=full` 跳过预览；自定义 `?scene=` 清单仍受支持。

## 测量与验收

同一台 Mac、Chrome、同一港科大场景，Brotli 静态服务，浏览器缓存禁用，CDP 限速 **2 Mbps 下载 / 150 ms 延迟**。等待画面可用、加载遮罩关闭和真实 FPS：

| 版本 | 首次可操作 | 此时画质 | 原模型画质就绪 |
| --- | ---: | --- | ---: |
| v1 | 64.864 秒 | 原模型 | 约 65.2 秒 |
| v2 | 6.918 秒 | 轻量预览 | 68.588 秒 |

**这是缩短进入等待，不是把完整 15.4 MB 下载变成 7 秒。** 此次受控模拟不能代表朋友的实际家庭宽带。静态图 LCP 不能准确表达可漫游 3D 就绪，故记录此业务指标。

本地完整验收与线上 CDN 复验均通过：14 个模型各请求一次预览和一次原模型，全部真实渲染；8 张合集卡片、筛选、搜索、首页不下载 SOG；港科大/PanDORA/OmniPhotos 三组共 9 张照片，1440/390 px 下全部回位、固定世界平面、查看原图、继续漫游及无横向溢出。手机尺寸为浏览器模拟。故意阻断预览/原模型、重试后相机不重置、完整画质模式和自定义清单均另行通过。

海外 CDN 在未切换前的两轮同机冷浏览器测试为 4.23/4.10 秒（完整模型），先前源站 6.24/6.61 秒；这些是阶段性线路样本，不保证全网提升。新资源首次填充 CDN 缓存时曾出现一次预览回退和 3 项预热失败/invalid；保留失败证据，重试与实际完整下载后重新验收全部 14 个模型通过，不能把首次失败抹掉。内容哈希 URL、HTTPS 校验、缓存命中和源站/CDN 的预览 SHA256 一致性另行核查。

北京、广州、深圳的 Globalping **数据中心探针**确认域名已解析至 EdgeOne、HTTPS 证书有效并返回 200；它们不是居民宽带，也没有测量浏览器渲染。大文件探针会截断返回内容，未用其 download 时间冒充全模型下载速度。朋友再次实际体验仍是验证国内线路的必要补充。

## 复现

已提交全部预览与 `preview-manifest.json`，普通构建无需重新转换或安装转换器：

```sh
node spaces/deploy/verify.mjs
node spaces/deploy/build-server.mjs .deploy/new-release
```

重新生成预览时，在单独工具目录安装 `@playcanvas/splat-transform@3.3.3`，然后执行：

```sh
node spaces/deploy/generate-previews.mjs /absolute/path/to/splat-transform
```

转换脚本使用 `-H 0 --decimate 75000` 输出临时 PLY，再以 CPU 编码 SOG；原始文件只读。已有预览必须与记录中的源文件/输出 SHA256 一致；不覆盖不明来源的旧预览。临时 PLY 和日志留于 `.task/mainland-speed/decimation/`。

测试依赖 Playwright 和 Chrome，可用 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定已有安装：

```sh
node spaces/deploy/test-server.mjs https://spaces.maxxam.xyz/spaces/ output-prefix
node spaces/deploy/test-progressive-recovery.mjs https://spaces.maxxam.xyz/spaces/
```

完整证据保留于本 checkout `.task/mainland-speed/`：`throttled-comparison.json`、`local-v2-acceptance.json`、`live-v2-acceptance-recheck.json`、失败的首轮输出、`local-recovery.log`、`deploy-receipt.json`、DNS/预热回执、真实截图。`validation-20260912.json` 是可提交的简明指标副本。
