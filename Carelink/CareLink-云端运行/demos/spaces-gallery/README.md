## 体验范围

这是静态前端设计预览；用户添加的内容只保存在当前浏览器。没有接入真实账号、AI 或跨设备共创。A 保留较早的交互实现，B–E 覆盖更新的流程，本轮用于比较视觉和操作感觉。

晴空、映场、拾光共享一个本地数据区；粉金原稿和暮蓝暗房各自独立。切换前保存草稿；请不要在多个标签页同时编辑同一条记录。

此前粉金版保存在 `classic.html`，原来附带的文件、最初设计稿和 Git 历史均保留。旧的 `#home`、`#space/...` 等入口转到粉金版。

照片为沿用的界面示例，来源在各版中标注；QR 工具许可证仍在 vendor 目录。此仓库只包含静态演示页面，不含后端、个人试用记录或研究材料。

GitHub Pages 从 main 分支根目录发布，无需构建依赖。
