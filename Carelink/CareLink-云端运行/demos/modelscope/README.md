# UNSEEN｜把活动现场散落的照片，变成共同记忆空间

UNSEEN 是面向线下活动、婚礼、聚会和社群运营的多人影像共创工具。参与者通过活动码进入同一个空间，上传各自拍到的照片；系统提供方向建议和置信提示，在不确定时交给用户确认，帮助运营者更快整理活动现场的分散素材。

## 体验路径

1. 进入首页，创建活动或输入活动码加入。
2. 上传现场照片，补充拍摄方向或使用系统建议。
3. 在共同空间查看其他参与者上传的内容，形成可持续沉淀的活动记忆。

## 当前实现

- 本创空间通过 Gradio 承载已上线的 UNSEEN Web 版本。
- 业务数据与图片上传沿用现有线上服务，创空间代码中不存放密钥。
- 当前方向能力是粗粒度方位建议，并非精确空间定位。
