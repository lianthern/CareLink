# 当天可用的双端 Demo

保留用户 HTML 的粉蓝手帐、便签、照片纸边及绿色听/红色说按钮；从同屏模拟改为两台设备各自使用。颜色沿用纸白 #FFFCF7、天空蓝 #A9D3F3、手帐粉 #F4AFC4、薰衣草 #C8B8EE、墨色 #57537C、薄荷 #8FD3B0。标题使用原文件内嵌 ZCOOL KuaiLe，正文用系统中文字体。

手机从当前照片进入发送，下方为家人的原声与记忆；相框以照片为中心，底部只保留听、说和切换照片。设置、邀请和资料在独立对话框里，处理状态必须反映后端结果。没有家人内容时显示空状态，不预填虚构故事。

手机：家庭/在线状态 → 当前照片 → 发照片/留言 → 记忆列表。
相框：时钟/连线 → 大照片/字幕 → 听 + 说。

已对照原稿：保留粉蓝手帐，不引入新的配色或营销首页。入口改成独立角色，桌面也能使用家人端。文字内容与原声分别保存。
