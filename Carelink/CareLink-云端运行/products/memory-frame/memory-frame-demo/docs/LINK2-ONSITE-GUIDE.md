# Link 2 → Kevin 相框：现场连接教程

核对日期：2026-09-24。适用于现有 Kevin-Link2-0.4.8-PRIVATE 私有运行包。

需要分清账号、Kevin 配对或调整检测区域/驻足参数时，先看 [Calibration 与账号说明](LINK2-CALIBRATION-AND-ACCOUNTS.md)。线上 0.4.9 与这个设备包兼容；调参在 Windows 本地窗口，管理绑定使用家人端 owner。

## 连接关系

Link 2 摄像头 → USB → Windows 电脑 → 互联网 → unseen 云服务 → Kevin 相框。

Windows 和相框都需要联网，但不要求同一局域网。驻足检测在 Windows 本地运行，只上传驻足事件；不上传摄像头视频或人头框。这不是人脸身份识别，也不判断视线。

## 现场准备

1. 一台 Windows 电脑、一台 Link 2、可用 USB 数据线，以及原来已配对为 Kevin 的相框设备。
2. 在 Windows 的“下载/unseen insta360”中找到 `Kevin-Link2-0.4.8-PRIVATE.zip`。完整解压；已存在同名解压目录时可直接使用。
3. 该包已包含运行时和配置，无需另装 Node 或重新编译。包内含私有凭据，只交给这台设备的管理员，不发群聊、不上传公开仓库。
4. 现有绑定是 `living-room-link2 → Kevin`。无需为了试用再开家庭或轮换令牌。

## 按顺序启动

1. **接摄像头。** 这台 Windows 只连接一台 Link 2。关闭正在占用摄像头的相机、会议、OBS、Link Controller 等程序。
2. **开相框。** 在 Kevin 原来配对的浏览器中刷新相框页面，保持前台、有照片、非夜间时钟且空闲。不要为了测试退出或重新配对。
   - 相框入口：https://memory-frame-demo-d7djiee0702b6c.service.tcloudbase.com/frame
3. **启动 Windows 程序。** 在完整解压目录双击 `START-KEVIN.cmd`，保留控制台和摄像头检测窗口。不要再手动启动第二份 Demo。
4. **站到摄像头前。** 保持在可识别范围约 4–6 秒，观察 Windows 日志和相框。实际触发还受检测质量、冷却和相框状态影响。
5. **确认邀请。** 相框出现“和 AI 聊聊”邀请后，在约 15 秒内确认。确认后读取当时固定的照片，显示一条轻柔的文字问题；不会自动开麦或朗读。可以打字，或手动选择语音输入、朗读回复。
6. **重试或结束。** 重试前离开摄像头视野，等约 30 秒再回来。结束时按 Ctrl+C 或关闭摄像头检测窗口。

## 三个成功标志分别看

| 观察位置 | 成功标志 | 说明 |
| --- | --- | --- |
| Windows | `captured presence.dwell eventId=...` | 本机生成了驻足事件 |
| Windows | `uploaded ... status=200 attempt=...` | 云端接受了事件，不代表相框已确认 |
| Kevin 相框 | 出现邀请，确认后出现照片问题 | 现场交互链路完成 |

这三项需要现场逐项观察。已有接口测试不能代替真实 USB 摄像头、相框点击、麦克风或扬声器验收。

## 常见问题

| 现象 | 按此顺序检查 |
| --- | --- |
| 找不到摄像头 | USB 数据线与接口、仅接一台 Link 2、其他程序是否占用。若提示缺少 C++ 运行库，由设备管理员安装微软官方 VC++ 运行库。 |
| 没有 `captured` | 人是否在画面内、是否停留足够时间、是否已经离开并经过冷却、Windows 时间是否正常。 |
| 有 `captured`，没有 `uploaded` | Windows 网络、时间、错误状态码。401/403 会停止上传，需要管理员检查绑定，不要复制旧令牌反复重试。 |
| 已 `uploaded`，相框没有邀请 | 是否是原来配对的 Kevin 浏览器；是否前台、有照片、空闲；是否在夜间时钟、对话、录音、播放或 3D 操作中；事件是否已经过期。 |
| AI 问题没出现 | 先确认邀请是否已点击；AI 不可用时仍可打开普通对话，不会强行开启语音。 |

断网恢复不会无限补发旧事件：上传器只保留有限的新鲜事件，避免回来后连续弹旧邀请。

## 到期与新增设备

现有 Kevin 绑定最晚于 **2026-09-30 18:40:03（北京时间）** 到期；相框退出、移除或传感器被停用可能使其提前失效。重新配对后，需要在家人端设置的“管理相框驻足邀请”中重新绑定并更新本地私有配置。

增加第二台相框时，先配对并命名新相框，再建立独立设备 ID 和对应绑定。不能直接复制 Kevin 私有包的凭据，否则会向 Kevin 发事件。当前原始 EXE 按单台 Link 2 使用，不承诺一台电脑多摄像头部署。

## 当前能力边界

当前可验收的是“摄像头驻足 → 定向邀请 → 确认后照片文字对话”。**TRTC 实时语音尚未接通，连续边说边听、打断、真人通话效果尚未验收。** 购买或领取 TRTC 权益也不能替代剩余配置、流式接入和真人验收。
