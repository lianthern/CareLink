# 老人相框、手机预览与 AI 语音完善

日期：2026-09-23。用户确认平板就是老人使用的相框，手机由家人管理并预览相框效果。参考最早 `reference/memory-frame-v4.html`，保留手机“首页 / 中央加号 / 我的”顺序。

## 本轮范围

- 平板相框突出照片、大字和大触控按钮，以“听原声 / 说一说”为主要操作；家人管理与展示分开。
- 手机增加相框效果预览。预览不是设备配对，不应上报相框在线、观看或听取回执，也不改变登录身份。
- AI 实时语音补齐音频就绪与挂断确认流程，保留显式点击开麦和退出、后台释放资源。

## 接通条件

总控在本轮真实运行离线 `check-trtc-readiness.mjs --config cloudbaserc.local.json`。结果为 `serviceEnabled=false`、`configurationReady=false`、`networkRequests=0`。provider、TRTC AppID、签名密钥、控制 SecretId/SecretKey、LLM JSON、TTS JSON 七项缺失；房间权限、独立清理与供应商联调仍未验证。

本轮界面与代码完善不能代替服务开通、真实麦克风/扬声器、真人插话及费用验收。未购买、开通或扩大云权限。实际部署状态在本文件完成记录中另列。

## 必验边界

- 平板横屏与竖屏、手机窄屏：主要操作可见，无横向溢出；长留言可阅读。
- 预览打开、关闭、切账号及内容刷新不产生写操作或残留上一家庭内容。
- 等待 AI 音频、超时、挂断未确认、重复点击与迟到响应均不重新开麦或产生重复语音任务。
- 已有文字聊天、草稿、照片、原声录制、历史分页与 3D 权限边界保留。
