## 本轮行为

- Windows 采集源码和 Node 上报器位于根目录 `devices/link2-windows/`。使用每台相框独立的传感器凭据；有限队列、超时、幂等重试及停止清理。保留已有 0.4.7 云接口，不用旧 MVP 共享令牌或广播行为覆盖。
- 相框驻足只展示邀请。确认后 AI 读取邀请固定的照片并温和地问一句；内部提示不显示成老人发言。不自动开麦或朗读。关闭、停止、后台、照片失效及忙碌保护保持，失败可继续普通聊天。
- 家人端接受影石时光舱作品网页链接或单链接分享文字，“寄出并导入空间”自动启动导入，显示失败阶段并允许重试。不是普通视频重建，也不是任意 ZIP/本地模型上传。
- 前后端共用链接解析，资源主机精确限制及逐跳 DNS/IP 固定、4 MiB 每段权限、完整摘要保持。真实授权样例可用，没有扩大白名单的依据。用户未提供另一条具体失败链接，不能断言其根因。
- Kevin 现有绑定不轮换。下载目录的 `Kevin-Link2-0.4.8-PRIVATE.zip` 含原 RAR 预编译采集器、配套 DLL、Node 和私有绑定；14 文件逐一验证，配置预检通过。真实摄像头未启动、C++ 未用 SDK 重新编译。公开仓库只带审阅文本源码，不带该私有包。
