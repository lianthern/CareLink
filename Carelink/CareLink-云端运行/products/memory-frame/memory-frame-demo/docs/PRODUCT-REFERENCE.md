## 本产品采用的关系与顺序

账号代表使用者；家庭划分内容及访问权限；相框是由家人配对的设备；记忆人物是内容标注，不能当成登录账号或自动推断的血缘关系。账号注册、加入家庭、配对相框是不同动作。登录只能恢复自己的家庭权限。

家人端保留原稿的首页、中央加号发送、我的顺序。首页依次呈现家庭与相框状态、当前记忆、上传或录音入口、人物年代、家庭故事。发送抽屉使用照片或空间入口，并保留可选文字与真实原声。相框继续使用绿色听原声、红色说一说。

空间是记忆的可选内容，主动打开时才加载。下载或渲染失败不能显示成正在观看；照片、原声和来源页仍可使用。原声、人工修订、待确认 AI 整理分别保留。统计与活动状态以真实存储或有效上报为依据，不以设备在线推断人在观看。

原稿的计时模拟录音、TTS 冒充原声、固定随机二维码、图片拖动冒充 3D、假识图标签、固定统计和模拟云处理均不作为可用功能。当前仍没有系统后台推送，人物与时间轴可浏览范围仍受最近 150 条记忆窗口限制。
