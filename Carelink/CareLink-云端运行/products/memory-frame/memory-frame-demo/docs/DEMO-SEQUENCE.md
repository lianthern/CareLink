## 原型示意与真实边界

原稿的相册演示素材、人物识别标签、TTS“原声”、模拟录音计时、假 3D 图片拖动、固定二维码、分享成功 toast、sleep 云流水线和 156/42/3 统计均没有照搬。当前记忆人物来自家人录入或待确认 AI 提取，节点不推断血缘关系。人物与年份筛选不新建人脸识别服务。

新回信提示仅在页面打开、同步到真实新回信时出现，没有系统后台推送。大字设置作用于当前设备；相框“夜间时钟”按本机 22:00–7:00 隐藏页面内容，不控制操作系统息屏，录音/播放/空间观看时不切换。点夜间时钟会关闭该模式。没有使用未经核实的“数据不用于模型训练”服务承诺。

当前接口只提供最近 150 条可浏览记忆。本轮人物计数和时间轴明确针对当前窗口，`stats` 为全部未移除记忆的服务端计数；不会用窗口大小伪装家庭总量。照片/原声/空间按记忆条数统计，可重叠。完整历史分页另需后端支持。

## 前后端契约

由本轮独立后端任务提供，不由前端伪造：

- `state.framePresence = {online,activity,messageId,frameId,frameName,updatedAt,expiresAt,message}`，`message` 为 `{id,title,imageURL,hasAudio}`；无有效上报时不把设备最近登录冒充正在观看。
- 仅相框调用 `framePresence({messageId,activity})`，活动为 `viewing/listening/recording/spatial/idle`。切换状态立即上报，同状态按 15 秒心跳上报；页面隐藏或无内容上报空消息的 idle。服务端验证家庭、消息、音频与空间状态并设 45 秒有效期。
- `state.stats = {photos,voices,spatial,replies,memories}`。旧服务缺少字段时显示 `—` 和等待同步。

前端新增 `server/public/family-experience.js`，由同源脚本加载；原 `app.js` 保留上传、录音、草稿、会话和 API 核心。轮询只刷新状态和只读列表，不重建发送抽屉、编辑表单或查看器。缓存版本 `0.3.0`。
