# 相框展示模式与真实通话入口

2026-09-24，基于 `35c915e` 的独立 `codex/frame-presentation` 实现。仅相框使用温暖米白、深墨文字、绿听/暖红说的页面样式；家人端主题另行整合。本任务未部署、未改云配置、未调用真实模型或麦克风。

## 使用

- 普通相框点“放大相框”进入覆盖可用视口的简洁展示层，隐藏页头及管理区域，保留照片、听原声、说一说、侧边翻页、轮播和“退出展示”。退出只恢复普通相框，不退出配对。
- 展示模式不依赖浏览器全屏，也不会自动请求全屏。“浏览器全屏”是额外的显式选择，使用 `document.documentElement`，因此已有录音、AI、空间与通话弹窗仍在全屏子树内。浏览器拒绝时保留页面展示并说明原因；全屏退出事件恢复普通相框。Escape 先关闭打开的对话框，随后可退出展示。
- 本次展示暂时挂起夜间时钟，避免跨过 22:00 时遮住正在使用的展示；退出恢复原有偏好，不写入更改后的夜间设置。
- 轮播默认关闭，每次开启按 15 秒换一张，不跨页面保存开关。手动翻页重置周期；后台不补跳。录音、等待麦克风、待发送原声、原声播放、AI 文字/实时会话、家人通话、空间/邀请/其他对话框、更多菜单、夜间时钟和后台状态都会暂停；恢复空闲后重新等一个完整周期。0/1 条记忆不能开启轮播。退出展示、失效、重新配对、卸载均释放轮播定时器。
- state 接到新照片时，如果正在上述操作中，不再替换当前展示照片；后台数据仍更新。原声回复仍绑定开始时的记忆，驻足邀请仍绑定触发时照片，原有去重、期限和确认语义保持。
- “更多”集中围绕当前照片聊、AI 实时语音可用性、站内联系提醒、和家人通话、空间及设置。当前记忆没有可观看空间时，说明由家人导入，并列出家庭其他已准备好的空间。模型依旧只在显式打开时按现有权限和分段校验加载，展示/轮播不加载模型。
- 家人端在现有页头设置旁也有“和家人通话”，首页、中央加号、我的顺序不变。`MemoryContact` 继续独立作为站内联系提醒，并明确不会拨打电话。`MemoryCall` 才是双方网页语音；加载现有模块、轮询状态可收到提醒，仍须选真实家人并确认呼叫/主动接听才允许后续媒体流程。未启用时显示服务端原因并禁用呼叫，不假称接通、不启用 TURN/TRTC 或购买服务。

## 生命周期与整合

新增 `frame-presentation.js/css`，样式均限制 `.elder-frame`，不修改共享 `style.css`、家人模板或 3D 查看器业务/画布。已有 AI/联系/通话/空间弹窗的文字、边线及按钮使用相同中性色。
