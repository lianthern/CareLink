## 对话体验

保留旧 UNSEEN 的照片事实与温和追问方式，并提供自然的日常多轮聊天。没有选择照片时，也能直接聊天，不能反复要求用户先提供照片。照片只是可选上下文。

用户可以选择一张或多张家庭照片，继续追问、比较照片或结合已提供的人物标注交流。界面显示当前参与对话的照片，可以增删；后续问题沿用明确选中的照片和有界聊天历史。初版拟设每次最多 4 张，最终按视觉模型能力和请求体上限核验，并向用户显示限制。未取得视觉模型结果时，不得假装看过图片；不凭脸部相似度认定人物身份或编造经历。

支持文字输入、主动录音后转写，以及可停止的回答朗读。浏览器朗读与云端语音合成应按实际来源记录，不等同于已具备实时语音通话。退出、切换账号、关闭交互或取消请求后释放录音和播放资源。

## 从聊天识别行动

用户可能说“给妈妈留句话”“把这两张照片发给爸爸”“帮我呼叫女儿”。AI 提出候选行动，支持文字留言、原声留言、照片留言和联系家庭成员。

收件人只能来自当前已授权家庭的真实成员。照片人物标签不是联系人；“妈妈”、同名成员或代词不明确时，应询问或让用户选择。缺少留言内容、原声、照片、联系对象或方式时，先补齐，不能自行代填。普通聊天不应强行转换成行动。

执行顺序：理解意图 → 补齐信息 → 展示确认卡片 → 用户确认 → 服务端执行 → 显示真实结果。

确认卡片清楚展示：收件人、发送方式、完整文字或原声试听、选中照片，或呼叫方式。提供“确认发送/呼叫”“修改”“取消”。用户修改任何关键内容后需重新确认，取消后不产生外发行为。

确认应绑定当前账号、家庭、候选动作 ID 与版本，不接受模型自行填写的 `confirmed: true` 作为授权。服务端再次检查收件人、媒体和权限，重复确认或网络重试不得重复发送。语音“确认”也只能对应当前已完整复述的候选动作；含糊回应应回到显式确认，不能误执行之前的动作。

留言必须有真实收件结果和可见范围。当前共享记忆流不能被包装成只对某人可见的私信；如复用家庭共享留言，确认时必须写明全家庭可见。若实现定向留言，则收件读取、媒体访问和通知都要执行对应权限。

家庭联系应区分呼叫请求已发出、对方接受、真实音频已连接、拒绝、取消和超时。只完成提醒或信令时，不得显示“正在通话”。对方未接听时，可让用户改为留言，并再次确认具体内容；不得自动向真实家人发起测试呼叫。

跨网中继与临时凭据通过受控管理员配置接入；没有满足启用条件的配置时，真实通话保持关闭并说明原因。先完成可审查代码和隔离测试，再列明需要的最小配置、权限、费用及真实设备验证。不得自动购买中继、扩大角色权限、向来历不明的公共中继交付家庭音频，或用模拟音频测试声称真人通话通过。站内提醒保留为用户主动选择后另行确认的备选。

## 模型与接入方式

优先使用既有腾讯 CloudBase 环境的模型接口，复用旧 UNSEEN 的对话设计和适配方式，不修改旧 UNSEEN 服务或复制其密钥。

| 能力 | 当前状态 / 实施选择 |
| --- | --- |
| 日常多轮聊天、意图候选 | 现有 `AI_MODEL=hy3`，通过 `createModel('cloudbase')`；新增对话/意图调用仍需实际验证 |
| 单图/多图理解 | 优先核验 `cloudbase` 下的 `kimi-k2.6`；官方支持图像输入，当前账号可用性、开关和额度尚待核验 |
| 语音转文字 | 复用现有腾讯 ASR；本轮真人麦克风闭环仍待验 |
| 回答朗读 | 首版可用浏览器语音合成，注明设备差异；不能声称已接通云端 TTS |
| 实际留言与呼叫 | 由应用受控接口执行，模型不能绕过用户确认直接操作 |

CloudBase 的接口入口统一，但各模型需要分别核实能力与实际环境配置。`hy3` 不支持图像输入。官方多模态示例中的 `glm-5v-turbo` 已公告于 2026-10-30 下线，不选作此新增功能的默认模型。`glm-5.3-flash` 是公告推荐替代，但未单独核验视觉能力前不能直接等同替换。

来源：[CloudBase 当前模型列表](https://docs.cloudbase.net/en/ai/available-models)、[多模态与多图输入](https://docs.cloudbase.net/ai/model/multimodal)、[GLM-5v-Turbo 下线公告](https://docs.cloudbase.net/en/ai/announcement/glm-5v-turbo-offline)。核验日期为 2026-09-23。不把平台文档中的“支持”写成当前账号已经开通或免费；新增费用/权限需求应单独提出具体差额。

## 必须覆盖的验收场景

- 无照片的正常多轮聊天，以及照片上下文增删后继续聊天。
- 两张以上照片共同输入与比较，视觉未配置/失败时显示真实状态。
- 明确、缺项、同名和有歧义的联系人识别；普通聊天不误触发发送。
- 确认前没有发送；确认卡片修改/取消后旧动作不能执行；重复确认只执行一次。
- 切换账号、目标成员被移除、媒体被删除、请求超时和重试时的正确结果。
- 定向留言的读取/媒体权限，或者共享留言的清楚告知。
- 呼叫未接听、拒绝、取消、超时与实际音频连接的区分。

接口/控制器自动化测试、模型真实调用、浏览器点击、真人录音和双设备真实通话分别记录，不能互相替代。
