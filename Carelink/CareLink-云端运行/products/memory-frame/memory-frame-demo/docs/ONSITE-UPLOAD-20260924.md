# 现场扫码上传 · 0.5.6

2026-09-24。用户要求沿用原后端，为现有账号和在线平板开放免注册扫码上传；最初提供的“001”在交接和真实登录中核为 `fixture01`。应用继续使用原 CloudBase 环境、家庭和相框配对。

## 已实现

- `/contribute?invite=…`：填称呼（可选）、选照片、捎一句话、寄出。一次最多 9 张；浏览器将图片缩至最长边 1920 并转为 JPEG。无法解码的格式提供改用 JPEG/PNG 的提示。
- owner 家人端“我的 → 邀请家人 / 配对 → 现场上传 · 免账号”生成二维码和链接，24 小时有效，默认 60 张独立照片配额。同一面板可关闭该链接。
- 扫码身份是独立 contributor，不是家庭成员。仅能上传自己的图片、发送照片和文字、查看自己照片的接收回执、退出；不能读取家庭照片/成员/历史，不能编辑、删除、配对、邀请、调用 AI 或其他管理功能。
- 邀请命名空间与原家庭/相框邀请码分开；关闭或到期后，已发出的访客会话同步失效。访客称呼由本人填写，不表示实名或注册身份。
- CAS 限额按唯一文件预留（包括尚未发送的文件）。每文件绑定一个发送 ID；前端用稳定文件 ID 发送，重复选择或丢失 HTTP 响应后刷新、重选不会重复寄出。额度已满仍可重试已上传照片。
- 照片写入原家庭消息，原相框轮询/展示/回执以及问答继续使用。所有该家庭相框都能接收，不是仅向某台硬件定向投递。
- “已上传”只说明云端保存；“相框已收到”使用真实 frame 回执。回执不是物理屏幕目视验收，也不是老人已看过或听过。
