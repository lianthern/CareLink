# 空间链接与双端查看界面

**2026-09-24新流程**：家人端中央＋ → 3D 空间，粘贴影石作品网页链接或包含单个链接的分享文字，点击“寄出并导入空间”。识别后保存规范链接并自动导入，旧记录仍有“导入空间”；错误显示阶段和恢复办法，其他来源不会假称已导入。前后端共用严格规则。见 [最新验收与操作](SPATIAL-LINK-ACCEPTANCE.md)，下面旧入口和测试数量仅为历史。

2026-09-23，分支 `codex/spatial-ui`。本文件只记录 UI 分支实施与证据；真实模型、下载安全及完整集成结果由总控合并后验收。

## 使用流程

家人端“给家里捎个信”中展开“添加影石空间链接”，粘贴自己有权使用的分享链接并寄出。链接随原消息保存，草稿也包含链接。合法影石链接在照片下方和记忆详情里显示“导入空间”；其他 HTTPS 链接保留原来源入口。

导入是单独的异步请求，轮询持续工作。页面显示后端的等待、导入进度、可观看或失败状态，不把请求提交成功当成模型成功。“导入中”仍可编辑草稿、寄照片和录原声。失败显示后端原因和“重试导入”，始终可以查看影石来源。相框端只能查看状态与打开已就绪空间，导入由家人端操作。

两端只有点击“打开空间”后才请求 `spatialAsset` 并动态载入 `/spatial-viewer.js`，完整 asset 原样交给查看器（包含可选视角字段）。独立对话框保留底层照片、音频和未保存的记忆修订；Esc、关闭按钮、页面离开、退出或 401 都会取消资源请求并销毁查看器。关闭时也取消尚未完成的初始化，过期返回的查看器会立即销毁。轮询只刷新独立状态面板，不重新构建查看器或编辑表单。

前端样式和脚本缓存版本为 `0.2.3`。

## 协议与边界

- 客户端入口匹配 `https://app.insta360.com/3dspace/detail/GS3DC` 加 32 位十六进制 ID，可带末尾 `/` 和查询参数；拒绝凭据、其他主机和自定义端口。服务端仍需独立验证，客户端不是安全边界。
- `spatialImport({id})` 返回 `{spatial}`；请求可等待后端有界导入完成。前端最多等待 160 秒，防止半开连接永久锁住重试。超时/断网只提示继续核对状态，不伪造服务端失败；退出/401 取消不显示误导错误。
- `state.messages[].spatial` 只用于显示 `queued/importing/ready/failed`、阶段、百分比、错误、来源标题和大小；未知阶段显示通用处理中。过期任务由后端归一化失败，使家人端可重试。
- `spatialAsset({id})` 返回资源对象；`refreshAsset` 仅在查看器仍打开且会话未变时可重新请求。不会读取提供商签名地址。
- `openSpatialViewer({container,asset,refreshAsset,onClose,signal})` 的同步或异步返回均支持 `{destroy,reset}`；本分支负责外层关闭与来源链接，模块负责渲染、复位和内部错误提示。

## 本机验证

使用 `mcp__cua_repl` 的独立 IAB 标签，端口 8793。先在原后端完成真实本地创建家庭、生成 fragment 配对链接、相框加入及双端在线；这部分没有 mock。创建的是一次性本地测试数据，没有读取私人配置。

后续界面状态和生命周期使用 `.tools` 中 Git 忽略的 HTTP fixture：它只模拟导入进度、失败、就绪、asset 和明确写有“MOCK 查看器（非真实模型）”的模块，**没有下载或渲染真实 SOG**。验证如下：

- 390×844 家人端、1280×900 相框端：保存链接后的导入入口、进度 37/82、失败原因、重试就绪、来源链接、两端查看器对话框，截图检查通过。手机文档宽 375（浏览器含滚动条宽 390），对话框 scroll/client 均 333；桌面文档宽 1265（含滚动条宽 1280），无横向溢出。
- 导入期间继续编辑草稿；未保存修订在多次轮询、导入完成和打开/关闭空间后仍保留。重新载入可恢复 IndexedDB 草稿。
- 请求资源 503 时显示真实错误与重新打开；mock 地址刷新回调成功。第一次导入后已发生 46 次 state，asset 与模块请求均为 0。查看器打开后累积 371 次 state，构建计数仍为 1；只有显式刷新才多请求一次 asset。
- Esc 返回原界面并释放；嵌套查看器关闭后焦点回到详情“打开空间”，未保存修订保持。401 自动关闭并显示重新配对入口。mock 最终共 4 次构建、4 次销毁，说明这些路径调用了释放；这不等于真实 GPU 内存测量。
- 专属 `node --test test/spatial-ui.test.js`：7 项通过；连同既有测试共 27 项全部通过。覆盖严格链接、重复提交去重、queued 不误报成功、160 秒半开超时、过期会话静默取消、资源迟到不构建、旧 dialog close 事件不误关新实例、状态刷新不请求模型。

不将 mock 证据称为真实导入/渲染验收。本分支没有验证真人麦克风、原生手机 GPU、云部署或真实资源过期；相关验收须在总控合并后继续。未改后端、查看器模块、原照片上传和原声处理实现。
