# TRTC 实际开通与验证方案

**2026-09-24 更新**：用户已要求优先免费接入；受限桥接已经实现并通过本地验证，账号侧仍未完成。当前状态与剩余步骤以 [TRTC-FREE-ACTIVATION.md](TRTC-FREE-ACTIVATION.md) 为准。下文“尚未授权/桥接仅为方案”是此前阶段记录。

核对日期：2026-09-23。适用于中国站、新接入的 unseen 记忆相框。用户先前要求“开通和费用稍后确认”，本轮要求进一步检查怎么接入；尚未获准购买套餐或产生 TRTC 用量。

## 当前账户与代码状态

- 已有 CloudBase hy3 普通聊天可继续使用。该模型负责回答，TRTC 提供实时音频及其 ASR/TTS 等链路；两者分别配置。
- 总控通过本机已有 CloudBase CLI 登录，执行只读 `trtc.DescribeTrtcSdkAppIdList`，返回 `AuthFailure.UnauthorizedOperation`。这只证明本次凭据无权查询，不能推断账户没有 TRTC 应用或没有免费额度。
- computer-use 能发现 Edge，但枚举页面、打开页面及重置后重试都出现 `nodeRepl.fetch request failed`，没有成功查看腾讯云控制台。本轮不能声称核验过账户套餐、余额、应用或权限。
- 本轮不新增云家庭、不创建 API Key、不扩展角色、不领取试用、不执行实时 Start。默认关闭的代码与普通聊天入口可以独立部署。

## 建议的开通顺序

1. 在 [TRTC 控制台](https://console.cloud.tencent.com/trtc/app) 检查现有应用与新用户福利；没有合适应用时，准备创建 unseen 专用应用，使用“自由集成（无 UI）”。先看清页面的后付费说明和服务协议，再确认是否开通。
2. 优先核对体验资格和可领的音视频、AI 智能语音抵扣包，不以购买大额包月套餐作为默认起点。试用功能资格和抵扣用量是不同项目；以该账户实际显示的资格与余额为准。
3. 确认 SDKAppID、应用签名密钥、房间权限与调用 Start/Describe/StopAIConversation 的服务端权限。凭据只保存于服务端私有配置；不在前端、Git 或交付包放密钥。现有 CloudBase 运行角色不会自动扩大。
4. 选择回答模型的接入方式。CloudBase 有 OpenAI 兼容 HTTPS 通道，但其 API Key 属于开发者/管理员级凭据，不能把它与普通短期聊天会话等同。直接交给 TRTC 的授权范围须单独评估；如果不接受该权限范围，可实现仅允许 hy3 文本流式回答、每会话鉴权的受限桥接。桥接是方案，不能写成已经存在并验证。
5. 按当前场景专用文档选择 `TTSType=flow`、`Model=flow_02_turbo` 和官方现成音色，暂不使用声音克隆。旧通用示例中仍有 `flow_01_turbo`，不能据此判定新接入配置已正确。
6. 配置独立的过期会话清理和供应商侧用量管理后，以受控的一次短通话检查签名进房、hy3 首字响应、TTS 播放、插话打断、静音、挂断、切后台、断网和供应商任务确实终止。用实际计费明细核对费用，再开放入口。前端 10 分钟限制不能保证供应商侧硬计费上限。

## 费用核对

2026-09-20 更新的中国站文档适用于 9 月 1 日起的新用户，说明开通后支持按量后付费。资源包用于抵扣；旧开通教程的套餐条件不能无条件套用到新账户。

| 项目 | 当前官方说明 | 本项目验证前的注意点 |
| --- | --- | --- |
| 音频通话 | 按 RTC 音频用量计费，包括机器人参与 | 先核对可用的音视频免费包与账户实际抵扣 |
| AI 实时对话服务 | 0.01 元/分钟 | 按任务运行时长统计，停止请求须真正生效 |
| 实时语音识别 | 新用户单价 0.017 元/分钟 | 以真实开麦及识别用量为准 |
| 基础 TTS（原 Flash） | 3 元/万计费字符，汉字按 2 字符计 | 使用现成音色；不能拿识别分钟数推断合成费用 |
| LLM | 按实际接入模型和账户规则另计 | 普通聊天已配置不代表 TRTC 外部调用鉴权已通过 |

官方另列 10000 分钟音视频免费包及 1000 分钟 AI 智能语音免费包；账号资格、有效期和抵扣范围分别核对。7 天体验只解锁功能，不等于全部费用免费；免费包用尽后可能继续按量收费。以上价格只是分项依据，未计算该账户实际账单，也没有承诺总成本上限。
