# unseen 记忆相框：家人和相框怎么用

> 0.4.9 使用说明：新增放大展示、可选轮播与统一视觉。实际部署、公开仓库及验收范围以 [0.4.9 发布验收](RELEASE-049-ACCEPTANCE.md) 为准。

家人在手机上寄照片、文字和原声；老人用平板相框看照片、听家人的声音，再录一段回信。

## 1. 先进入自己的家庭

- 手机打开[家人端](https://memory-frame-demo-d7djiee0702b6c.service.tcloudbase.com/family)。已有账号直接点“登录账号”，输入账号和密码；日常登录不用开通码。
- 第一次加入：请家庭创建者在“我的 → 邀请家人 / 配对 → 邀请家人”生成链接。在自己的手机上打开链接，填写账号、密码和称呼，点“注册并加入家庭”。账号为 3–32 位字母、数字、点、下划线或短横线；密码至少 8 位。
- 只有最初建立家庭的人才需要“注册账号 → 创建新家庭”，填写家庭名称和部署者提供的开通码。不要为了换设备反复创建家庭。
- 邀请链接有效 24 小时。若首次打开出现平台提示，先点“确定访问”；邀请没有自动带入时，可粘贴完整链接或邀请码。

## 2. 给平板配对

家人手机点“我的 → 邀请家人 / 配对 → 配对相框”。在平板浏览器打开生成的链接，填写“相框称呼”，点“完成配对”。也可先打开[相框端](https://memory-frame-demo-d7djiee0702b6c.service.tcloudbase.com/frame)，粘贴配对链接或邀请码。相框不需要注册家人账号；“邀请家人”和“配对相框”是两种不同的邀请。

## 3. 家人寄出，老人回复

1. 手机点底部中央“＋”。选照片，写一句话；也可以只写文字。
2. 要留原声，点“录一段原声”，允许麦克风，录好后点“结束录音并试听”。每段最长 60 秒。确认后点“寄到相框”。
3. 平板保持相框页面打开，几秒后收到内容。绿色“听原声”播放家人录音；没有录音的内容，该按钮不可用。左右按钮可换照片。
4. 老人想回复当前照片，点红色“说一说”，录好后点“结束录音并试听”，再点“发送给家人”。
5. 家人回到首页，在“家人讲的故事”或“收到新回信”中打开回信。可以听原声、修订文字、补人物和年份，最后点“保存修订”。AI 整理内容需要家人核对。

草稿只保存在当前浏览器，刷新后可恢复；发送失败时先保留页面并重试。首页的“预览老人相框”供家人预览，不会替老人产生观看或听取回执。

### 相框展示与高级功能

相框点“放大相框”，照片铺满页面，侧边切换上一张 / 下一张，底部保留“听原声”和“说一说”。需要时点“开启轮播”，每 15 秒切换；默认不轮播，少于两张时不能开启。录音、听原声、聊天、弹窗或页面切到后台时暂停，不会把正在操作的照片换掉。浏览器支持时可另点“浏览器全屏”；不支持也可继续页面展示。

点“退出展示”回到普通相框（不会退出家庭），再点右上“更多”：可围绕当前照片聊、选择已导入的空间、发送站内联系提醒、查看家人通话 / AI 实时语音是否可用，以及打开设置。当前照片没有空间时，会列出其他已准备好的空间。

“和家人语音通话”需要双方在线及已配置的音频中继。当前部署未启用，会明确显示原因，不会自动申请麦克风；它不同于无需通话服务的“联系家人 · 站内提醒”，也不同于 AI 实时语音。

## 4. 和 AI 聊天

首页点“和 AI 聊天”，输入文字后点“发送”。要看图，展开“添加家庭照片”，选择并添加照片，再勾选“让 AI 读取当前选中的照片”。最多选 4 张。可用时，“用语音输入”把录音转成文字，“朗读回复”读出回答。

“实时语音”是另一个入口。显示“尚未开通”时，可以点“返回文字聊天”；这时没有接通电话，也不会开启麦克风。聊天不会自动写入家庭记忆，留言需要另行检查确认。关闭文字聊天窗口后，临时聊天不作为长期记录保存。

## 5. 驻足邀请与 3D 空间

家庭创建者在“我的 → 设置 → 管理相框驻足邀请”中选择目标相框、填写传感器设备标识并签发令牌，再私下交给 Windows 设备管理员。每台相框分别绑定；令牌轮换后，设备端也要更新。普通家人没有这个管理入口。已有现场绑定请沿用，不必为了查看功能重新签发。详见[外置摄像头连接说明](EXTERNAL-CAMERA-SETUP.md)。

设备连接后，老人面前可能出现“想聊聊这张照片吗？”邀请。点“暂时不用”即可关闭；点“和 AI 聊聊”才会让 AI 读取邀请时的那张照片并先问一句。不会自动开麦或朗读。看到问题后，可打字回答，也可在语音输入可用时自行点“用语音输入”；横屏下若看不到回答/发送按钮，在聊天窗口内向下滑动。想中止生成可点“停止”或“关闭”；照片读取失败时仍可继续普通文字聊天。正在录音、听原声或聊天时，邀请不会排队稍后打扰。

3DGS 内容来自**影石时光舱作品分享链接**（即用户所说的“时光仓”）。在影石 App 打开已经生成的作品，选择分享中的“网页链接分享”；在 unseen 中央“＋ → 3D 空间”粘贴该链接，或包含一个作品链接的分享文字。按钮变为“寄出并导入空间”后，点它即可自动导入；等显示“空间可观看”，再点“打开空间”。普通视频、时光舱特效视频和本地 SOG/ZIP 不是这个入口接收的内容。

导入失败时，查看卡片中的原因；来源链接仍可打开，处理后可点“重试导入”。不要把“链接已保存”当成导入完成。新行为的实际验收范围见[流程审查记录](FAMILY-FLOW-AUDIT.md)。Windows 设备管理员另见[启动说明](../../devices/link2-windows/README.md)，日常使用者无需操作设备端命令。

## 常见卡住的地方

- 相框收不到：确认两端是同一个家庭，平板打开的是“相框端”，页面显示已连接；不要仅凭家人手机的预览判断相框在线。
- 不能录音：使用 HTTPS 页面，并在浏览器设置允许麦克风；重新打开录音入口。录好后还要点击发送。
- 邀请失效：请家人重新生成对应类型的邀请。
- 忘记密码：目前没有自助找回或改密码入口，请联系部署者处理。
- 本地便携版与线上是两套数据，账号不能互相通用。
