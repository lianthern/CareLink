# unseen 记忆相框：账号与家庭

账号提供跨设备重复登录的本人身份；家庭仍是内容与成员权限边界。相框是通过邀请配对的设备，不要求输入账号密码。现有邀请会话和家庭数据继续有效，不自动转换旧设备为账号。

## HTTP 契约

所有操作使用 `POST /api`，JSON 为 `{ action, data }`，已登录操作附带 `Authorization: Bearer <token>`。

| action | data | 结果 |
| --- | --- | --- |
| `register` | `username,password,nickname,mode:'create',name,setupCode` | 使用有效开通码创建家庭和 owner 账号，直接登录 |
| `register` | `username,password,nickname,mode:'join',invite` | 使用有效 family 邀请注册该家庭的 family 账号，直接登录 |
| `login` | `username,password,invite?` | 登录原有家庭；可选邀请必须有效、角色为 family、家庭与账号一致 |
| `logout` | `{}` | 撤销当前会话；其他会话保留，legacy/frame 会话也支持 |

注册与登录均返回 `{token,room,role,name,username}`。用户名去首尾空白、转小写，仅允许 3–32 位 ASCII 字母、数字、点、下划线和短横线；密码 8–128 个字符，不修剪空白。昵称默认用户名。

`state.username` 是当前账号名；`state.members[].username` 仅出现在账号会话上，供界面区分“移除账号”和“移除设备”。上述接口都不返回内部账号 ID、密码凭据、盐或摘要。账号与普通会话的内容授权完全相同。

`/api/health` 返回 `accounts: true` 以识别账号版本；首次账号版为 `0.4.0`，当前含云端空间分段传输的版本为 `0.4.1`。

## 授权、并发与恢复

- 注册没有开放匿名家庭创建：仍需开通码，或未过期、未撤销的家人邀请。frame 邀请不能注册家人账号。邀请不是一次性使用，保留原有 24 小时有效规则。
- 账号只绑定一个家庭。重复登录不会创建家庭或提升角色。用另一家庭邀请登录不授予该家庭权限。
- 用户名映射到确定性的私有记录 ID，存储 CAS 保证并发注册只有第一组密码生效；大小写变体也不能抢占或覆盖已有账号。
- 注册先保存带固定家庭 ID 的 `pending` 凭据记录，再幂等写入家庭并激活。家庭或会话写入失败后，用原密码重新登录/注册可恢复，不重复建家庭。相同密码的注册重试只可恢复原有注册意图。
- pending 家人注册仍需有效授权。原邀请过期后，可在注册或登录时提供同家庭的新有效 family 邀请；后端验证原密码后更新 pending 邀请并继续激活。
- 新注册与旧 `create` 共享持久家庭额度记录，最多 10 个家庭。失败写入的家庭预留保守保留；账号注册可重用自身预留，旧匿名 create 的失败预留需要维护者核查后处理。没有自动删除家庭或账号功能。
- owner 移除某个账号会话会先禁用账号，再撤销它的全部会话。API 每次检查账号状态，3D 私有地址也检查账号状态，因此会话清理部分失败仍不能重新登录或使用旧会话。当前账号不能通过另一台设备的会话条目移除自己，应使用退出登录。
- 移除普通邀请会话或配对相框仍只撤销该设备；撤销邀请仅停止后续加入，不影响已加入成员。持有另一有效邀请的人仍可注册新身份，这不是实名封禁系统。

## 凭据和尝试限制

密码通过 Node 异步 `scrypt` 派生，参数 `N=32768,r=8,p=3`，每账号随机 16 字节盐、64 字节摘要；只存算法版本、盐和摘要。校验使用固定长度时间安全比较。不存在、错误密码或已禁用账号的登录返回统一错误；不存在账号也执行一次同参数派生。

限流在密码派生前执行：持久 CAS 文档同时限制全局每 60 秒 60 次注册/登录尝试，以及每用户名 15 分钟内 10 次失败尝试。成功仅清空自己的用户名计数，不清空全局预算。用户名窗口最长保留 15 分钟，因此单一预算文档大小受全局次数上限约束；限流跨 CloudBase 实例和进程重启有效。LocalStore 是单进程文件存储，不支持多个独立写进程共同打开同一目录；测试的多实例共享同一个 LocalStore，另有重启读盘测试。

会话继续使用随机 token、服务端只存 token 的 SHA-256，并保留 7 天有效期。数据库保持客户端访问拒绝，账号和限流记录不会进入消息/成员内容列表。

本轮没有密码找回、改密码、邮箱验证、多家庭切换、账号重新启用或外部身份服务。原有照片/原声通过已签发的临时媒体地址访问：移除账号阻止后续 API，但已取得的照片/原声地址可能继续有效到临时地址到期（本地签发 15 分钟、云端签发 15 分钟；已缓存内容无法收回）。3D 地址另有每次会话/账号核验。

## 验证范围

`node --test memory-frame-demo/test/accounts.test.js` 覆盖 HTTP 注册、邀请第二账号、重复登录、重启读盘、frame 免密码配对、凭据不泄露、非法邀请、跨家庭拒绝、用户名并发、故障恢复、旧邀请过期换新邀请、退出登录、账号撤销、清理失败时 3D 失效、持久限流和共享家庭额度。

测试的图片/音频传输及浏览器视觉验收另见总体验收记录；该后端测试不宣称完成手机真实录音或浏览器视觉验收。没有增加依赖，使用 Node 20.19 已有的 crypto、util 和现有存储 CAS 接口。
