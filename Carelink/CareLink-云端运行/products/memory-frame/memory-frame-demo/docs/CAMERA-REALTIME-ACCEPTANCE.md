## 摄像头接口

实施分支 `codex/camera-presence`，提交 `cb2f0f0`、`9b2314a`、`b2c2d98`。合并前已做补丁等价检查；独立复审与总控集成复验均为 **35/35 通过**。

- 已核实官方 Link SDK 支持 Link 2，可读取人脸目标与隐私状态；未发现可直接声称“正在看相框”的注视接口。
- 提供默认关闭的本地观察协议、Link SDK 宿主注入接口、浏览器本地检测器接口，以及停留、冷却、离开重置和邀请回调。

- 复审曾复现拔线后重新启用无效，最终补丁已修复，并覆盖终止/临时错误区别、初始化中拔线、迟到回调和显式重启。
- 没有实际设备、检测准确率、眼球/视线、主动问候或扬声器测试。

资料：[官方调查](CAMERA-LINK2-RESEARCH.md)、[接口与接线](CAMERA-INTERFACE.md)。

## 普通聊天与实时 AI

原公网聊天入口：登录家人端或配对相框端后，在页面顶部“设置”旁点“和 AI 聊聊”；记忆详情也有“和 AI 聊这份记忆”。原功能支持文字、多轮、选照片及录音转写后发送、手动朗读。

本轮独立分支 `codex/ai-live-dialogue` 增加显眼的聊天入口和腾讯 TRTC 接入。普通文字回答继续使用既有 **CloudBase hy3**，照片仍使用 MiniMax-M3。实时层与模型分开配置，不挪用识图密钥，也不把语音识别/手动朗读描述为实时通话。

新源码在家人端/相框端家庭名称下方增加“有话想说，和 AI 聊聊”卡片，提供“和 AI 聊天”与“实时语音”；顶部也保留“AI 聊天”。原始“首页 / 中央加号 / 我的”顺序保持。新版尚未部署，不能把源码入口当作公网已更新。

实施提交 `584a484`、`dd7daee`、`719ea80`、`6b46302`，最后 `6a9081e` 仅更新主脚本缓存版本。合并前检查补丁等价；作者最终 **97/97** 定向测试通过。独立复审对前端进行了 48 项测试及真实模块的 VM 生命周期检查，覆盖关闭与麦克风授权迟到、未开通不加载 SDK、不请求麦克风等路径。总控复现并推动修复跨实例旧快照清理误停刚续租会话的问题，最终也保持已结束状态不被迟到停止改回。

腾讯 TRTC 服务尚未开通或配置。已完成代码不等于供应商可用、真实音频连通或达到某个延迟指标。实际 API、配置示例、开通前所需项目与验证步骤见 [实时 AI 接入说明](AI-REALTIME.md)。
