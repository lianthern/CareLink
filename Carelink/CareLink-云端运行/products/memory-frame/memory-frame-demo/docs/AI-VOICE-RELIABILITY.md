# 实时语音连接与挂断确认

2026-09-23，基线 `8b1fe30`，实施分支 `codex/voice-reliability`。本轮完善客户端生命周期，未改供应商、私有配置或云资源，未部署、购买或启用服务。

## 用户可见变化

- 本机进房和推流完成后显示“麦克风已开启，正在等待 AI 语音接通”。仅在本次机器人音频可用并成功请求接收后显示接通；陌生用户音频不能推进状态。音频可用不代表 AI 此刻正在说话，也不证明用户实际听见了声音，因此没有虚构听说活动指示。
- 等待期间仍可静音或挂断；30 秒未接通机器人音频则停止本机音轨并申请结束远端任务，不自动重连。服务端 Start 成功即安排心跳与本次总时长计时，避免慢进房消耗租约后迟迟不续租。
- 挂断请求失败或服务器仍报告 stopping 时，保留原 requestId，显示“确认已结束”按钮。只有服务器明确返回 ended 才恢复开始按钮；重试只停止同一个任务，不重新创建通话。
- 同一登录身份关闭再打开窗口仍保留待确认状态。旧窗口的挂断请求迟到成功或失败会更新新窗口；挂断在途时不会重复请求。待确认任务计入 busy，防止其他录音入口误认为实时会话已经完全结束。
- 保留原有安全清理：关闭、后台、断网、超时、迟到授权/进房/推流均释放本机资源，所有重启仍需用户手动点击。

待确认状态只保留在本页面内存，按登录 token 隔离，没有把会话或音频写入浏览器持久存储。整页刷新后仍由现有服务端持久记录、租约和清理流程限制重复任务；不能据此声称后台停止或计费已经确认。真实开通仍需完成 [TRTC 接入准备](TRTC-READINESS.md) 中的私有清理部署与供应商验收。
