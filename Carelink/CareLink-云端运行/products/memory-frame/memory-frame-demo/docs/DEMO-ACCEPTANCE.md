## 请用户实际操作验收

入口：[家人端](https://memory-frame-demo-d7djiee0702b6c.service.tcloudbase.com/family) / [相框端](https://memory-frame-demo-d7djiee0702b6c.service.tcloudbase.com/frame)。刷新并使用已有账号，无须新建家庭。

识图操作：进入“和 AI 聊聊”，选择家庭照片后点“添加到对话”，勾选“让 AI 读取当前选中的照片”，再输入问题。

| 勾选 | 操作 | 预期 |
| --- | --- | --- |
| [ ] | 刷新登录，依次打开首页、加号、我的 | 中文字体统一、无缺字，顺序保持 |
| [ ] | 不选照片，聊日常并追问上文 | 可连续聊天，不强行弹留言候选 |
| [ ] | 添加一张实际照片并勾选读取照片 | 描述可见内容；看不清时说明，不编造身份经历 |
| [ ] | 添加两张不同照片，问共同点和区别 | 区分两张照片及顺序，比较实际内容 |
| [ ] | 语音输入一句话，结束、修改转写再发送 | 主动授权录音，文字可编辑；关闭后麦克风停止 |
| [ ] | 朗读回答，再点停止或关闭 | 有声音且可停止，音色取决于设备 |
| [ ] | 说“给家人留言：我晚上六点回家” | 先选真实对象、核对确认卡；未确认前不发送 |
| [ ] | 留言附照片或本次原声，先修改/取消，再准备确认 | 预览准确，旧卡失效；家庭共享范围明确 |
| [ ] | 用另一已有家庭账号/相框查看已确认留言 | 原文和照片相同，原声可播放 |
| [ ] | 发送站内提醒，另一端确认收到 | 双方显示状态，不出现“电话已接通” |
| [ ] | 退出并登录另一账号，再打开AI | 不泄漏上一账号聊天、录音或候选 |
| [ ] | 打开历史照片及已有3D内容 | 分页可用；3D显示、触控和关闭正常 |
