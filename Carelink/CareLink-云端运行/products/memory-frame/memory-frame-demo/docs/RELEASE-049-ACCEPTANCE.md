# 0.4.9 展示模式、视觉与 X6 兼容

2026-09-24，总控独立 `codex/frame-showcase-integration`。本页区分合成浏览器、真实影石作品、公网 HTTP 与现场设备证据；不把前轮验收数量当成本轮完整回归。

## 本轮变化

- 老人相框增加“放大相框”，以照片、侧边上一张 / 下一张、绿色“听原声”和暖红色“说一说”为主。可选每 15 秒轮播，默认关闭；录音、播放、AI、通话、弹窗、菜单或后台期间暂停并保持当前照片。退出展示停止轮播，不解除家庭配对。
- 退出展示后“更多”集中照片聊天、已有 3D 空间、站内联系提醒、家人语音通话、AI 实时语音和设置。浏览器全屏单独由用户触发，失败仍保留页面展示；失效会话退出展示以露出重新配对入口。
- 家人端统一米白、墨色、绿色操作和暖红录音；首页照片优先，保留首页 / 中央＋ / 我的顺序。通话入口出现时手机顶栏采用两列，操作目标至少 44px。
- 家人 WebRTC 通话入口与轮询生命周期接线。服务未配置时明确显示未启用，不申请麦克风、不发起真实通话；站内提醒、家人电话和 AI 实时语音不混为一项功能。
- 通话模块补原声录音授权中、实时语音、离线及迟到媒体的门禁。CloudBase 发送预算改为可整体替换的数组，保留有效窗口内的旧计数并正确清空过期窗口。
- X6 只增加核实后的精确资源主机 `p1-app.insta360.com`，逐跳 DNS / IP / TLS、文件类型、预算与分段鉴权保持。验证相机矩阵后选择首次拍摄中更接近水平的姿态，X5 原取景不变。

- 家人精修分支：14 项现有浏览器 / 实际本地 HTTP 流程通过，27 张 320 / 390 / 1280 及大字截图已查看。临时 DOM 的四按钮排版预览不代替最终接线验收。
- X5 / X6：均真实读取用户授权作品，完整导入 SOG v2、各端读取 4 段并校验整文件摘要，家人和相框 PlayCanvas 软件渲染通过。最终网络、解析与相机定向 77/77 无跳过；X6 初始倾角从 47.75° 调整为 2.76°。见 [专项验收](SPATIAL-X6-ACCEPTANCE.md) 和 [脱敏报告](SPATIAL-X6-VERIFICATION.json)。没有向云端重复导入模型。
- 通话后端 / UI：独立审查发现等待录音授权时再次申请麦克风、未停止脱离 DOM 的相框原声，以及新增互斥条件导致迟到实时心跳漏释放三个缺口；最终均修复并以独立复现及 7/7 定向复核关闭。预算修复有实际 CloudBase SDK 离线序列化及两实例 CAS 验证。
