# 老人相框与家人端预览（2026-09-23）

平板作为老人相框，回到早期 `reference/memory-frame-v4.html` 的照片主场景：柔白框、天空色衬底、对比清晰的文字叠层、下方绿色“听原声”和红色“说一说”大圆按钮。横竖屏均保留真实录音、原声、翻页和现有 3D 入口；联系/设置收进“更多”。AI 入口保留，实时面板放大；服务未开通仍由既有能力检查禁用。

家人首页增加“预览老人相框”。预览是独立只读弹窗，明确标记“不会切换家中相框或标记已读”，按钮仅作示意，不创建 frame session，不播放音频、不申请麦克风、不报告 presence/receipt。独立选择不会更改家人首页或录音关联；轮询刷新预览内容和媒体 URL，记录删除退回剩余内容/空态。关闭、登录失效、退出/切换时移除内容。

## 本地验证

- Chrome 153.0.8010.49，真实 headless 页面与点击，静态 HTTP + API 替身，无业务服务写入。
- 平板/桌面 1366×900、1180×820、1024×768、1280×800、820×1180；手机 390×844、320×780。检查无横向溢出、大按钮至少 110 px 且初始视口内、更多设置、未开通实时面板、手机独立选择/禁止回执与 presence/关闭/URL 刷新/删除空态/失效清理及底部顺序。
- `elder-frame-browser.test.js` 与 `family-ui-lifecycle.test.js`、`history-ui.test.js`、`ai-conversation-ui.test.js` 共 67/67；另账号与空间 UI 16/16。
- 测试图片是明确的 SVG 风景替身。未使用真实家庭照片、真人麦克风、实体平板或 GPU 3D 渲染；不能替代这些实机验收。

浏览器测试设置 `AI_UX_PLAYWRIGHT` 与 `AI_UX_CHROME` 后运行；`AI_UX_SCREENSHOTS` 可选指定截图目录。不设置浏览器路径时该测试明确 skip。
