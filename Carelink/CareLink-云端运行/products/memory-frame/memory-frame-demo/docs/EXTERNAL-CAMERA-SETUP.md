# 每台相框分别连接外置摄像头

用户于 2026-09-24 确认采用每台相框分别绑定外置摄像头的方式。0.4.7 已支持独立传感器绑定，无须改变云端事件协议。

## 连接关系

```text
摄像头 A → Windows 采集/上报器 A → 云端 → 相框 A
摄像头 B → Windows 采集/上报器 B → 云端 → 相框 B
```

每个采集/上报实例使用自己的 `deviceId` 和传感器令牌。服务端固定家庭与目标相框，不能由上报请求临时改目标；不会把事件广播给家庭内其他相框。Windows 与相框各自能访问现有 HTTPS 服务即可，不要求同一局域网。摄像头画面留在采集端，协议只接受驻足事件。

当前对接方交付的是 **Link 2 + Windows** 采集/上报方案。其他品牌或通用 USB 摄像头需要对应的采集适配，不能把接上 USB 等同于驻足检测可用。多摄像头接在同一台 Windows 时，采集端还必须明确选择设备、隔离各进程；对方现有文档没有证明这一能力，云端多绑定不能替代这一硬件验收。

## 增加一台

1. 在目标相框设备上完成原有家庭配对，取容易辨认的名字，保持相框页面打开。
2. 用家庭管理员登录家人端，进入“设置 → 管理相框驻足邀请”。
3. 填写本家庭内不同的设备标识，例如 `bedroom-link2`，核对目标相框名称、ID 尾码和在线状态，再签发令牌。
4. 在对应 Windows 采集端设置 `PRESENCE_SENSOR_TOKEN` 和相同的 `PRESENCE_DEVICE_ID`，由 `start-cloud-uploader.ps1` 启动采集与上报。不要同时另开第二份占用同一摄像头的 Demo。
5. 打开该相框的原有 `/frame` 页面，保持前台、有照片、非夜间时钟且空闲。实际驻足后，核对 Windows `captured`、`uploaded` 与相框邀请；检查其他相框未受影响。0.4.8 中邀请明确说明读图用途，老人确认后才打开固定照片的 AI 对话并先问一句；不会自动开麦或朗读。

每个家庭当前最多配置 8 个不同的传感器标识；停用后可以复用原标识。第二台设备不能直接复制第一台令牌。设备标识是 1～64 个字母、数字、点、下划线或短横线。

令牌有效期不超过目标相框会话。相框退出、移除或到期时需重新配对并绑定；更换摄像头目标时先停用旧绑定，再为原标识签发。轮换令牌会立即使旧令牌失效，Windows 配置也需更新。
