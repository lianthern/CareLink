## 初始集成契约

以下契约已在本轮合入并通过本地验收；云端仍运行此前版本。

- 消息仍通过 `send` 保存 `link`，兼容现有 HTTPS 来源链接；仅允许的影石分享链接才显示模型导入按钮。
- `POST /api` action=`spatialImport`，data=`{id: messageId}`：家人端为本家庭消息启动或重试导入，返回 `{spatial}`。后台下载与照片/录音上传通道分开。
- `state.messages[].spatial`：`{id,status,stage,progress,error,sourceURL,sourceTitle,provider,bytes,digest,updatedAt}`；状态 `queued/importing/ready/failed`，不存在则未导入。轮询不得返回模型内容或触发下载。
- action=`spatialAsset`，data=`{id: messageId}`：已授权家庭两端主动打开查看器时返回 `{url,bytes,digest,format:'sog',sourceURL,sourceTitle,provider}`。URL 有限时效，需支持重新请求；不得泄露提供商签名原始地址。
- 云函数生命周期协调：首次 `spatialImport` 请求保活至有界导入结束，前端以独立异步请求提交并继续轮询状态，不阻塞收发；重复请求返回现有状态。整个流程需低于现有 150 秒云函数超时，配合持久租约、过期重试和工作者校验，不依赖响应返回后仍有后台算力。
- 查看器模块 `/spatial-viewer.js` 导出 `openSpatialViewer({container,asset,refreshAsset,onClose,signal})`，同步返回 `{destroy,reset}`。`asset` 是 `spatialAsset` 结果，另含可选的验证后 `view={position,forward,up,fov}`；关闭时释放 WebGL、事件、网络和临时 URL。UI 用动态 `import()` 延迟加载。查看器负责真实错误提示与复位控件，UI 负责外层关闭和打开来源页。
- 安全策略保持同源脚本；若确有 worker、WASM、云签名资源等需求，由查看器任务明确报告给后端/总控，只开放必要来源。
- 暂不承诺原生手机、微信真人录音、实机 GPU/内存指标、完整漫游/碰撞或云端新版部署。
