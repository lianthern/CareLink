03 · ANDROID STUDIO

安装 Android Studio 2025.1.1

  1. 双击下载的 android-studio-2025.1.1.13-mac_arm.dmg。
  2. 把 Android Studio 拖进“应用程序”文件夹。
  3. 打开 Android Studio，按首次启动向导完成基础设置。
  4. 如果系统提示是否导入旧设置，可以选择不导入，保持一个干净环境。
必须使用 Android Studio 2025.1.x。不要用当前最新的 2026.x 安装 PICO Emulator。如果电脑已有新版 Android Studio，可以保留两个版本。
04 · ANDROID SDK

安装 Android 15 / SDK 35

  1. 打开 Android Studio → Settings → Languages & Frameworks → Android SDK。
  2. 进入 SDK Platforms，勾选右下角 Show Package Details。
  3. 展开 Android 15.0 (VanillaIceCream)。
  4. 勾选 Android SDK Platform 35 和 Sources for Android 35。
  5. 点击 Apply 或 OK，等待下载完成。
05 · PICO PLUGIN

安装 PICO Spatial Plugin

  1. 打开 Android Studio → Settings → Plugins → Marketplace。
  2. 搜索 PICO Spatial。
  3. 澳大利亚和其他海外地区选择 PICO Spatial (Global)。
  4. 安装完成后点击 Restart IDE。

Marketplace 无法下载时

  1. 打开 PICO Spatial 全球资源页，下载插件 ZIP，不要解压。
  2. 在 Android Studio 中选择 Settings → Plugins → 齿轮图标 → Install Plugin from Disk。
  3. 选择 ZIP，安装后重启 Android Studio。
06 · EMULATOR

在 Android Studio 中下载 Emulator

  1. 打开 Settings → Languages & Frameworks → PICO Spatial Tools。
  2. 勾选右下角 Show Package Details。
  3. 勾选 PICO Emulator。
  4. 建议同时勾选 Spatial Editor，但网页演示并不强制需要。
  5. 点击 Apply 或 OK，等待组件全部下载完成。
07 · LAUNCH

启动 Emulator 并打开 UNSEEN

  1. 从 Android Studio 的 PICO Emulator 工具入口或 Device Manager 打开虚拟设备。
  2. 如果没有 PICO 虚拟设备，按界面提示创建一个，然后点击播放按钮。
  3. 等待 PICO OS 6 桌面完全启动。
  4. 在 Emulator 中打开 PICO Browser。
  5. 如果无法输入文字，点击左侧工具栏的 Enable Keyboard Mode。
  6. 打开下面的 UNSEEN PICO 地址。
  7. 点击浏览器地址栏里的“安装”，然后回到应用库打开 UNSEEN PICO。
https://unseen-locator-lab.maxorila.chatgpt.site/experiences/pico-spatial

如果只停留在浏览器标签页中，空间效果可能不会完整启用。应先安装，再从 PICO 应用库启动。

10 · TROUBLESHOOTING

常见问题

找不到 PICO Spatial Tools
确认已经安装 PICO Spatial (Global) 并重启 Android Studio； 同时确认 Android Studio 是 2025.1.x，而不是 2026.x。
Emulator 下载失败
确认可用空间不少于 40GB，并更换稳定网络后重试。如果访问 Google 或 PICO 资源异常，可以尝试关闭 VPN 或更换网络。
Emulator 黑屏或运行很慢
确认是 Apple 芯片 Mac、内存至少 16GB；关闭占用内存较大的软件。 第一次启动通常比之后更慢。
网页显示成普通平面网页
确保运行 PICO OS 6 Emulator，在 PICO Browser 地址栏点击“安装”， 然后从应用库里的 UNSEEN PICO 图标启动。
展会现场没有网络
优先播放提前录制的 MP4。若必须离线交互，需要把网站项目和依赖也复制到 展会电脑，并在本机启动开发服务器。Emulator 访问 Mac 本机时使用：
