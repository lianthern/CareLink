## 3. Max 最新且覆盖旧稿的明确决定

### 3.1 暂时移除阿见的图形形象

现有“会折角的小相片 + 两只眼睛”的阿见形象审美不成立，下一版先从所有关键界面中移除，不再把它作为入口 hero、照片挂件、加载角色或成品说明角色。

先统一改成纯文字状态：

- 看图中：`阿见正在看这张照片……`
- 看完后：`阿见看到了：……`
- 提问与失败回退仍用文字表达，不放替代插画或新吉祥物。

这不是永久删除品牌角色，而是冻结图形形象，等 Max 之后单独重做。不要在本轮自行生成另一只吉祥物。

### 3.2 黑色是外部舞台，不是某一页的临时皮肤

- 入口、照片选择、对话、模板选择、成品外部舞台保持中性黑 `#050505`。
- 蓝色只做少量焦点、麦克风或快门标记，不做大面积 CTA。
- 照片、相纸、海报、zine 内页可以使用米白、白色、黄色或其他材质色。
- 成品页不能把整个 `body` 翻成米白；只能让成品纸张在黑场中发亮。

### 3.3 下一次交付必须是一整圈完成版

不要再推“只改一个颜色”“只接一个按钮”的中间版本。下一次交付至少同时完成视觉、语音、模板主链和真实设备验收，让 Max 能够一次完整体验后再评价。

## 4. 建议拆成的 Worktree

### Worktree A · 视觉主链

目标：把入口 → 照片 → 对话 → 模板选择 → 成品做成一套完整黑色暗房体验。

必须完成：

- 移除阿见图形角色，换成文字状态。
- 入口的主角是一个可点击/上传的照片槽，不再是普通标题 + 大蓝按钮落地页。
- 照片上传后不默认强裁为 4:3；对话照片优先保持原比例，海报等明确裁切模板除外。
- 对话页减少大块亮色卡片；照片占第一视觉层，观察与问题是文字注记。
- 形态选择页必须在手机和桌面都显示真实照片的成品预览，不能再用灰色占位线。
- 一页、海报、zine、立体四种卡片必须一眼可区分；三套风格需用真实照片展示材质差异。
- 切换 shape / style 只更新预览，不提前提交或破坏稳定 ID / 事件合同。
- 成品外部保持黑色，单图不重复显示无意义的照片缩略栏。
- 360×640、390×844、430×932、1280×720 无横向溢出，触控目标至少 48px。
- 遵守 `prefers-reduced-motion`；不能用常驻粒子掩盖排版问题。

### Worktree B · 语音与对话可靠性

目标：把现有语音输入从“代码接上”提升为“真实可用且失败边界诚实”。

必须完成：

- 原生 `SpeechRecognition / webkitSpeechRecognition` 的开始、停止、处理中、完成状态完整接线。
- 中文 interim / final 文本合并进可编辑 textarea，保留用户原有文字，不重复、不丢字。
- 权限拒绝、无麦克风、无语音、网络错误、不支持和启动失败都能立即继续打字。
- 返回、换照片、重开记忆或重复启动时，旧识别会话不能迟到污染新会话。
- 处理中禁止重复启动；取消不显示伪错误。
- 回见不创建、不上传、不保存录音文件，界面文案与实际行为一致。
- 真机/真实浏览器至少覆盖：Android Chrome 允许与拒绝、iPhone Safari 能力探测与回退、桌面 Chrome 中文识别。
- 若受当前验收环境限制无法完成某个真实设备 canary，必须明确标记为未通过，不能用 fake API 代替最终结论。

本轮“语音”默认指语音输入转文字，不自行扩张成 TTS、配乐或云端录音。

### Worktree C · 模板、导出与持续记忆主链

目标：把已经存在的功能完整走通并消除“看得见但用不成”的接口。

必须完成：

- 单图：一页回忆、记忆海报、立体记忆均能真实预览、切换风格并导出。
- 多图：2–24 张排序、主图、zine 真实翻页、分享长图、逐页 PNG、打印 / PDF。
- 三套风格在预览与导出中保持一致；不得出现预览黑色、下载却固定相纸等分叉。
- 轻立体只做轻透视；粒子每张照片最多播放一次且只在边缘，减少动态效果时诚实降级。
- 本机合集保存、刷新重开、继续添加、继承风格、改名、精确删除都必须真实落到 IndexedDB。
- 重开记忆后保留真实照片数量、shape、style 和原合集保存目标，不误覆盖到“这一年”。
- 无 IndexedDB 时明确显示无法本机保存，不能回报假成功。
- 账号、云端、跨设备和 UNSEEN 自动同步仍不在本轮范围内，界面不得暗示已经具备。

### Worktree D · 独立终验（总控可自己执行，但不得边验边暗改）

目标：合并后只基于用户可见行为作出通过/退回决定。

必须验证：

- 自动测试、全部 JS/MJS 语法、`git diff --check`。
- 真实 MiniMax 首问不是 fallback，且不虚构时间、关系、地点、情绪或事件目的。
- 入口 → 单图 → 语音/文字 → 原话确认 → 四种形态/三种风格 → 导出 → 本机保存 → 刷新重开。
- 多图重排 → 主图提问 → zine → 分享/逐页下载 → 保存合集 → 继续添加 → 删除。
- 360 / 390 / 430 / 1280 每个关键屏幕截图、计算背景色、横向溢出、最小触控区。
- 控制台 warning / error、麦克风权限头、noindex、服务健康、线上静态文件 SHA-256。
- 部署前备份 `/opt/huijian`；部署后只重启 `huijian.service`，不碰 UNSEEN。

任何 P0/P1 未清零，不能推公网让 Max 验收。
