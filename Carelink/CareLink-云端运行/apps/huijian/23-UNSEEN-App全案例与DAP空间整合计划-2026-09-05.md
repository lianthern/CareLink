## App 信息结构与布局

保留三个一级位置：**回忆 / ＋ / 我的**。“＋”是新增动作。假设沿当前已审视觉扩展而不换框架；依据是用户要适配既有 UI；若后续微调名称，组件和数据无需重做。

1. **回忆首页**：品牌和个人续看区域 → 大幅“走回现场”空间主卡（真实 DAP 封面与明确进入按钮）→ “留下一段回忆”照片入口 → 分类示例预览及“查看全部”。空间卡与照片入口均在手机首屏附近可发现；不同时挂载多个 3D canvas。登录后适量显示最近个人内容，公共示例仍可找到。
2. **全部示例**：全部 / 空间现场 / 照片与原话 / 纪念册与短片，DAP 在空间分类靠前；同一场景多种观看方式聚合在详情，不堆重复封面。技术提供方和细节放详情说明，来源与 AI 标识保持清晰。
3. **空间详情**：统一返回、标题、模式切换（原图 / 360 / 空间，按实际能力显示）、最大化、复位、暂停与照片条。手机竖屏先让画面可看，工具收进底部抽屉；横屏扩展画面，退出恢复原列表滚动与选择。DAP 不要求用户理解 shaders 或元数据才能看。
4. **＋ 新建**：先选“照片聊回忆”或“空间回忆”；空间下有“上传全景”和“导入 DAP 成果”，并接回已有 World 照片生成入口。全景与深度适用对象明确：2:1 全景 + 可选现场照片；已有 DAP 导入需配对全景、深度图和元数据/manifest，不存在统一的 `.dap` 文件就不能凭空发明这种格式。高级说明提供具体支持格式与样例包。
5. **我的**：回忆 / 空间 / 任务，统一显示草稿、上传中、生成中、可查看、失败需重试；设置保留原入口。创建开始不强制登录；选择本地素材和预览可先做，云端保存/私有任务提交时登录并保留当前内容。公开示例不会自动进入个人空间。

此次顺带修复已确认的 `/app#me` 刷新误回首页及相关路由历史问题，因为新增案例与空间深链都依赖它。最小示例管理后台、邀请开户/找回等 #22 待办仍单独排队；不可用后台建设拖住案例接入，也不能新增另一套账号系统。

## 数据、DAP 与上传合同

### 统一案例与账号

扩展现有服务器发布目录为带类型的 catalog（photo-memory / panorama / dap / world / book / video 等），复用 `unseen_demo` 作为示例归属与维护身份。现有官方资产发布为明确版本，源记录可维护、公开读模型只读。公共发布是明确操作，不扫描或自动公开整个账号；游客不写入 demo 账号。可以先提供可靠的幂等维护/发布命令，完整后台不是本轮前置。

个人空间、深度、原图和任务使用 canonical 的现有账号、空间及私有媒体权限；如需 schema/API 增补，在 canonical 隔离工作树实现。不要在 HUIJIAN 再造 SQLite 账号库，不通过编辑一个 demo 静态 JSON 假装实现跨设备个人存储。

### DAP 两类编码必须显式适配

- 历史 `tools/depth.py` 产物：PNG + 每张图独立 `min/max`、`near_small`、尺寸、原图信息。当前 ballroom 渲染器反归一化、乘 100、1.8–6 的显示范围、12% 视觉强度、最大约 0.42m 受限移动是该样例标定，不自动适合所有输入。
- canonical 产物：`unseen-depth-artifact/1` / precursor，`linear-red-v1`、near/far、sha256、panorama revision、quality 与方向 envelope。复用 `packages/viewer/src/depth.js` 和现有 viewer-adapter 校验。
- 分版本解析/转换并记录转换来源，不把两者混读；源图/深度/元数据/照片方位必须属于同一场景和版本。移除固定宴会厅限制要以真实输入校验替代，不能仅删除一行检查。
- 导入落盘后实际加载深度和原图；刷新、退出重进及另一授权会话能恢复。缺深度、尺寸不符、损坏、元数据异常应明确报错或显式降到 360，绝不仍显示“空间已生成”。原始用户素材保留。

### 上传全景并生成 DAP

“导入已完成成果”与“上传新全景生成深度”分别验收。优先复用已存在 DAP 权重和生成实现，完成新 App 上传 → 私有素材 → 可恢复任务 → 实际 worker → 产物校验 → 查看器 → 我的空间。不要把上传表单放上去、实际永远排队或只有演示 fixture 当作完成。

开工实测现有推理运行环境和生产可部署能力，选择适合当前服务器的执行路径；旧 Mac/8777 流程只是算法来源，不能让正式 App 暗中依赖未声明的开发机常驻进程。若生产缺少可靠算力，继续交付 DAP 成品导入、全部案例与 UI，并为生成子项给出真实运行证据、部署依赖和缺口；该子项仍为未完成，不因局部上线抹掉。不得另购云 GPU、扩大付费配额或恢复 4060 训练来绕过资源问题。

文件导入须在现有媒体能力下校验类型/尺寸/体积与解析失败，manifest 只引用本次上传或明确获授权的资源，避免路径穿越和任意远程拉取。登录归属、版本绑定、幂等请求、失败恢复及后台任务状态沿 canonical 语义。普通用户只上传素材或成果，不上传并执行模型权重/任意脚本。

World 单/多图生成复用已存在 API、配额、同意流程和任务对账；未知结果先查询，不重复消耗付费任务。已有 World 结果优先用于免费查看验收。自有 SOG/SPZ/PLY 等是独立格式，仅为找到且有真实 loader 的类型提供入口；不要把 DAP PNG 当 3DGS，或承诺任意格式都可读。
