# 回见 vNext M2 + M3：大改版实施合同

日期：2026-09-01

状态：执行中

基线：`codex/vnext-full-product`，继承已经验收通过的阿见看图对话、语音转写、轻透视、单次粒子、单页 PNG / 打印导出与“不猜”边界。

## 一、这次交付的产品结果

这次不再把单图、相册、模板和持续记忆做成四个互相抢入口的小工具，而是接成同一条手机主链：

> 选一张或多张照片 → 先围绕主照片说出一点记忆 → 选择做成一页、海报或一本 zine → 选择三种视觉风格 → 保存到本机合集，之后能继续添加、重开、导出或删除。

本轮完成 M2 与“本地优先”的 M3。跨设备账号不在独立站伪造：页面明确说明本机保存边界，并提供连接 UNSEEN 的入口；只有真实接入 UNSEEN OTP 与存储合同后，才把它称为跨设备保存。

## 二、对象和任务

- 核心对象：手机里已经有照片，但缺少整理动力、表达入口和可保存成品的人。
- 核心任务：不是修图，而是让照片背后的原话更容易被说出来，并迅速变成可以重看、分享和继续添加的记忆物。
- 第一次成功：访客不登录也能从照片走到一个真实成品并下载。
- 再次成功：刷新或隔天回来，能从“我的回见”重新打开本机合集，沿用同一风格继续加照片。

## 三、信息结构与流程

```text
暗房首屏
  ├─ 选择 1 张 ──→ 主照片对话 ──→ 成品选择
  └─ 选择多张 ──→ 第一张作主照片对话 ──→ 成品选择
                                           ├─ 一页回忆
                                           ├─ 记忆海报
                                           ├─ 一本 zine（2 张以上）
                                           └─ 立体记忆（实验）
                                                     ↓
                                           选择视觉风格
                                           傍晚相纸 / 黑色碎片 / 极简留白
                                                     ↓
                                           本地下载 + 保存到本机合集
                                                     ↓
                                           我的回见：重开 / 续加 / 删除 / 导出
```

分叉规则：上传前不展示模板；先完成至少一个回答，才出现结果形态。形态和风格是两个维度，不把它们混叫模板。

## 四、视觉设计合同

### 色板

- 深夜蓝 `#142536`：暗房工作台与主背景。
- 相纸白 `#FFF9EA`：可保存成品的纸张底。
- 快门蓝 `#8BC4DE`：聚焦、选中、轻操作反馈。
- 串灯黄 `#F2C55C`：一次性粒子与少量温度提示。
- 记忆红 `#B64942`：印章、书脊与删除确认，不作大面积警报色。
- 石墨 `#26333D`：纸面正文与暗色层次。

### 字体角色

- 展示角色：`KaiTi` / `STKaiti`，只用于“回见”、封面题名与阿见开场，不进入长正文。
- 阅读角色：`PingFang SC` / `Microsoft YaHei` / system-ui，用于对话、答案和操作。
- 档案角色：小号无衬线、较宽字距，用于日期、张数、页码和“只存在这台设备”等来源说明。

### 布局候选与拍板

候选 A（采用）：单一照片入口，主链内渐进分叉。

```text
┌────────────────────┐
│ 回见          我的 │
│                    │
│   ┌────────────┐   │
│   │            │   │
│   │  选照片     │   │
│   │  1 张或多张 │   │
│   └────────────┘   │
│     示例体验        │
│  照片仅用于本次看图  │
└────────────────────┘
```

候选 B（否决）：首屏平铺“单图 / 海报 / 相册 / 3D / 空间”卡片。它会在用户尚未感受到阿见价值时制造选择压力，读起来像模板商城。

手机成品页：上方为横向形态胶片带，中间为成品舞台，下方只保留一个主行动；桌面端变成左侧照片胶片、中间预览、右侧风格与保存，不另造一套产品。

### 标志性元素

仍以“照片边缘只出现一次的粒子聚拢 + 轻微透视”为唯一动态标志。zine 的书脊、接触表和页码只做结构语言，不再叠加常驻粒子、全屏星空或自动轮播。

### 反模板化自检

- 不使用渐变英雄区、功能宫格、玻璃拟态面板或万能圆角卡片墙。
- 首屏只有照片入口与弱化的本机记忆入口。
- 成品必须像相纸、海报或一本书，而不是同一张卡片换三个标题。
- 黑色碎片风格的粒子不能越过主体中心，`prefers-reduced-motion` 时退回静态。

## 五、能力合同

### 1. 多图采集

- 文件选择器支持 1–24 张 JPG / PNG / WebP；每张最大 30 MB。
- 先压缩为适合看图与本地存储的 JPEG；读取失败只移除失败项，不清空其余照片。
- 选中多张时第一张为主照片，支持在进入对话前重排或移除。
- 首轮只向模型发送主照片；多图 zine 不把所有照片自动上传给模型。

### 2. 结果形态

- `memory-page`：一页回忆，沿用照片、日期、问题与原话。
- `poster`：单张竖版分享海报，突出照片和一句用户原话。
- `zine`：封面 + 多页 + 尾页；至少包含整页、双图、网格和文字留白四类版式，按选择顺序确定性编排；支持翻页、上一页 / 下一页和手机滑动。
- `spatial`：复用轻透视与一次粒子；能力不足时明确回退原样。

### 3. 三套视觉风格

稳定 ID：`evening-paper`、`black-fragments`、`quiet-white`。三个 ID 尽量同时作用于一页、海报与 zine；未实现的组合必须禁用并说明，不能点了没有变化。

### 4. 本机持续记忆

- IndexedDB 存储 `memories`、`collections` 与 `styleProfiles`；数据包括照片、可见事实、问题、用户原话、拍摄 / 创建时间、形态、风格和版本。
- 用户能创建 / 命名合集，默认提供“这一年”；合集保存默认沿用自己的 style profile。
- “我的回见”展示合集封面、记忆数、最近更新时间；支持重开、续加、改名、删除。
- 删除前显示确切对象与不可恢复说明；失败不提前从 UI 消失。
- 页面始终写清“保存在这台设备的这个浏览器里”。清浏览器数据或换设备不会自动出现。

### 5. UNSEEN 桥接

- 本轮只提供指向 `https://unseen.maxxam.xyz` 的“创建 / 进入多人空间”入口和能力说明。
- 不复制 OTP 表单，不声称回见本机合集已经同步，不把未上传内容写成已进入空间。

## 六、导出合同

- 一页与海报：纯浏览器 Canvas PNG；长中文不截断，失败保留“再次下载”。
- zine：至少支持平铺分享长图与逐页 PNG；打印 / PDF 保留为系统能力。
- 取消打印不等于已保存；实际成功生成下载后才更新保存状态。
- 所有导出保留用户原话，不由模型润色或补写。

## 八、验收门槛

1. 旧单图文字与语音主链不退化；AI 看不清时仍可完成。
2. 360、390、430 CSS px 下，多选、对话、结果选择、zine、我的回见都无横向滚动；主要触控区至少 48 px。
3. 一张照片只能选择一页、海报或立体；两张以上才开放 zine，禁用原因可见。
4. zine 有封面、多页、尾页和真实翻页；不是把页面拼成单张海报冒充书。
5. 刷新后本机合集能重新打开；同一合集新增记忆时默认沿用已保存风格。
6. 一页 PNG、海报 PNG、zine 平铺图和逐页 PNG 均在本地生成；用户原话和中文长文本完整。
7. 减少动态、无语音支持、IndexedDB 不可用、下载被拦时均有可继续的降级路径。
8. 自动化、语法、diff 检查与真实浏览器主链全部通过；没有 P0 / P1 后才能推送 GitHub。

## 九、明确不伪装完成的范围

- 回见独立站的真实邮箱登录与跨设备同步。
- 把本机合集自动写入 UNSEEN 空间。
- 服务端原音频保存、TTS 语音伙伴、真实深度分层或重 WebGL 3D。
- HEIC 的跨浏览器解码；本轮提供可理解的格式提示，继续列为 iPhone canary。
- “自动记住你的人格”或不可见画像。
