# 回见 vNext M0 + M1：实施与验收记录

日期：2026-09-01

集成分支：`codex/vnext-integration`

结论：**代码与本地浏览器验收通过；发布前只剩真机 canary，不包含部署授权。**

## 本轮交付

### 单图语音主链

- 保留访客态“选一张照片 → 阿见先说可见事实 → 只问一个问题 → 原话成页”。
- 回答框支持浏览器原生中文语音转文字；点一次开始、点一次停止。
- interim 与 final 转写进入同一个可编辑文本框，确认前可修改；已有手打文字不会被覆盖。
- 权限拒绝、无声、网络错误、无麦克风、浏览器不支持和启动失败都回到文字输入。
- 回见不创建或保存音频文件；页面说明由浏览器语音服务完成转写。

### 原样 / 轻立体效果样片

- 同一张照片可即时切换“原样”和“轻立体”。
- 轻立体只增加小幅透视和一次照片边缘粒子；粒子不穿过中心主体，也不会来回切换时重复播放。
- `prefers-reduced-motion`、Canvas/3D 能力不足会同步恢复并锁定原样模式。
- 360px 手机宽度没有横向溢出；照片控制按钮和“重新选照片”触控高度均为 48px。

### 本地成页与导出

- 结果页保留原照片、日期、问题和用户确认后的原话，不润色。
- PNG 完全在浏览器 Canvas 中生成；中文按 grapheme 换行，长内容会增加画布高度，不截断空行或段落。
- 自动下载被浏览器拦截时，保留可重复点击的 Blob 下载链接。
- 打印 / PDF 样式仍可用；仅打开后取消打印不再被误记为“已经保存”。
- 未保存时，重新开始和离开页面仍有保护提示。

### 阿见的诚实边界

- 首问不得把 facts 没写出的时间、关系、身份、情绪、事件目的当成既定前提。
- 首问不得让用户替 AI 确认照片里的物品、颜色、数量、材质或位置。
- 已有可靠 facts、但模型问题越界时，保留“我看到了”的事实，问题替换为固定安全句：

  > 这张照片之外，还有什么是你想留下的？

- facts 本身缺失或响应损坏时，才进入“这张我没看清，所以我不猜”的整体降级。
- 追问仍可使用用户原话里已经明确说出的时间、关系与情绪。

## 验收证据

### 自动化

- `npm test`：35 / 35 通过。
- 覆盖语音开始/停止、interim/final、错误回退、旧会话迟到事件、粒子边缘约束、单次播放、减少动态、中文换行、长 PNG、下载回退、首问 guard、打印状态与触控区合同。
- `node --check`：前端模块、provider 与 server 通过。
- `git diff --check`：通过。

### 服务与真实模型

- `/healthz`、前端 ES modules 与演示照片均返回 200。
- 真实 MiniMax 能返回客观 facts；最终回归中越界原问被安全替换，同时保留 facts：
  - facts：两只手持着高脚杯碰杯；背景有暖色夕阳和模糊串灯；
  - question：这张照片之外，还有什么是你想留下的？
  - `degraded=false`；`questionFallback=unsupported_initial_premise`。

### 浏览器与响应式

- 实际走通：首屏 → 演示照片 → 阿见观察 → 首问 → 文字回答 → 基于原话续问 → 提前结束 → 原话成页。
- 实际走通：原样 / 轻立体切换；轻立体状态和短时粒子；回去编辑原话。
- 360 / 390 / 430 CSS px：无横向溢出；桌面保持 544px 窄画布，不变成复杂控制台。
- 实际生成 PNG：1240 × 1754；浏览器控制台没有 warning / error。
- 独立 QA 初次给出的两个 P1——越界首问、取消打印误记保存——均已修复并有回归测试。

## 仍需真机确认

这些不是代码自动化可以代替的证据：

1. Android Chrome：允许 / 拒绝麦克风、中文转写、停止录音、断网回退。
2. iPhone Safari：是否暴露 `webkitSpeechRecognition`；不支持时应只保留完整打字路径。
3. Safari 与 Chrome 各点一次实际 PNG 下载；系统打印 / PDF 对话框各看一次。
4. 系统开启“减少动态效果”后确认照片保持原样。
5. iPhone 相册 HEIC canary：本轮只接受 JPEG / PNG / WebP；确认真实选择器是否能提供兼容格式，再决定 M1.1 是否加 HEIC 转码。

## 本轮明确未做

- 未部署、未发布到公网。
- 未做登录、服务端持久保存、多图、相册模板、长期记忆、TTS 或完整深度图 3D。
- 未保存原始语音。
- 未接产品分析事件；`voice_started`、`voice_transcribed`、`local_exported` 等仍在后续发布准备里。

## 下一步顺序

1. **先做 2 台真机 canary**：Android + iPhone，各走一遍语音、文字、导出、减少动态；只修 P0/P1。
2. **再决定是否发预览环境**：真机通过后由 Max 明确授权部署，本轮不默认上线。
3. **用真实完成率决定 M2**：先看用户是否完成回答、导出和再次打开，再开始“一页 / 一本 / 立体记忆”结果系统。
4. **M3 再接账号与合集**：首次成品之后才提示登录，保存可见、可编辑、可删除的持续记忆。
5. **M4 最后接空间**：只有同一活动/同一批照片出现真实多人数据，再连接 UNSEEN 空间。
