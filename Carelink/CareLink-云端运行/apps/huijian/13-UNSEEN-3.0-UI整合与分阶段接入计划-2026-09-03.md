# UNSEEN 3.0：UI 整合与分阶段接入计划

> 2026-09-04：Max 已同意先接入 P0 最短闭环。样机原有信息架构与设计语言保留，真实能力和后置能力在同一套 UI 中清楚分级。

## 1. 本轮要解决的问题

当前产品不是缺功能，而是入口与对象关系没有被一套 UI 讲清：

- “回见”照片对话、UNSEEN 活动空间、World Lab 和历史成品能力各有入口；
- 粒子、2.5D、360、3DGS、Marble 容易被用户理解成五个不同产品；
- 一页、海报、zine、立体记忆容易在上传前制造选择压力；
- 首页、底部导航、创建卡和实验入口之间存在重复。

UNSEEN 3.0 先用一套纯前端样机冻结信息结构和设计语言，再进入功能接线。

## 2. 设计依据与取舍

### 2.1 继承自 iCloud《回忆时刻》Demo

保留：

- 粉、雾蓝、淡紫、珍珠白、旧金组成的“柔光纪念册”视觉；
- 宋体标题与克制英文档案标记；
- 照片画廊、邀请、共同上传、回忆对话、成品分享的完整情绪链；
- 一次集中的空间漫游动效，作为记忆被重新进入的视觉隐喻。

收缩：

- 底部从“首页 / 空间 / ＋ / 回忆库 / 我的”收成“看看 / ＋ / 我的”；
- 首页不再并列两个重复的创建入口；
- 取消无依据的平台规模数字，所有样例统一标记“设计演示”；
- 减少装饰性玻璃卡、扫光与飘落元素，提高正文对比和字号；
- 所有可点击元素使用真实按钮/链接语义，并提供键盘焦点与减少动态模式。

### 2.2 设计令牌

| 角色 | Token | 用途 |
|---|---|---|
| 雾蓝 | `#DCE8FB` | 背景冷光、信息状态 |
| 柔粉 | `#F4DCE8` | 背景暖光、人物记忆 |
| 珍珠白 | `#FFFDFC` | 主表面、相纸 |
| 旧金 | `#C7A56A` | 主行动、可信边框 |
| 墨紫 | `#352F46` | 正文与标题 |
| 灰紫 | `#746C86` | 辅助文字 |

字体角色：展示标题使用宋体族；正文使用系统中文无衬线；档案标签使用窄字距的系统等宽体。

### 2.3 标志性元素

样机只保留一个强记忆点：**回忆长廊**。首页主视觉把真实例图排成一条向画面深处延伸的相框长廊；点击后进入空间详情。其余页面保持安静，让照片和用户原话成为主体。

## 3. 信息架构

### 3.1 一级入口

```text
看看                     ＋                     我的
公开空间与作品        统一添加来源         自己拥有的资产
```

- `看看`：示例空间、共同记忆和公开作品；不是第二套创作工具。
- `＋`：拍照、相册、视频、邀请四种来源；不先问算法或成品类型。
- `我的`：最近记忆、空间、作品、草稿与任务；资料和设置继续后置。

### 3.2 上传后再分流

```text
素材进入统一舞台
  ├─ 聊聊这张（默认主行动）
  ├─ 加入现场
  └─ 走进照片（实验）
```

- “聊聊这张”承接现有 AI 看图与语音/文字单轮对话；
- “加入现场”承接活动、邀请、共同上传、定位与共同叙事；
- “走进照片”统一承接粒子、2.5D、360、真实 3DGS 与 AI 补全，不让供应商名称成为入口。

### 3.3 结果层

一页、zine、海报、视频和可走空间只在已经形成记忆后出现。系统按素材数量和上下文给默认结果，用户可以换形态，但不会在上传前先选模板。

## 4. 样机覆盖范围

本轮 `/unseen-demo` 需要可点击展示（`/unseen-3` 保留为内部别名）：

1. 启动页与“看看”首页；
2. 统一添加抽屉；
3. 例图选择与统一照片舞台；
4. “聊聊这张”的对话与一页回忆结果；
5. “加入现场”的示例活动空间；
6. “走进照片”的真实性分级与实验选择；
7. “我的”资产首页；
8. 直接跳转各画面的演示目录。

所有上传、生成、保存、分享和加入动作只改变本地演示状态，并持续显示“设计演示 · 未连接真实功能”。

## 5. 队友评审门

样机通过以下问题后才进入接线：

- 第一次打开的人能否在 10 秒内说出产品是做什么的？
- 是否自然理解“＋”先选来源、再决定用途？
- 是否能区分“聊照片”“加入真实现场”“AI 补全空间”？
- 是否认为三个一级入口足够，还是有高频目的地被埋得太深？
- 粉金柔雾是否像 UNSEEN，而不是婚礼模板或美颜 App？
- 示例图、文字、动效是否足够真实，能支撑产品讨论而不是只看静态稿？

评审输出只接受三类结论：`通过`、`带修改通过`、`重做信息架构`。没有结论前不接后端。

## 6. 评审通过后的接入顺序

### P0：共用外壳与最短闭环

- 把 UNSEEN 3.0 壳接到现有 `spatial-lab` 单图主链；
- 接入真实照片选择、MiniMax 看图、文字/语音回答；
- 形成一页回忆并保存到本机；
- 旧 9 项粒子参数移到实验室，不进入消费主界面。

验收：手机完成“＋ → 选图 → AI 问一句 → 回答 → 留下一页 → 再打开”。

### P1：多图与成品

- 接入 1–24 张选择、重排与删除；
- 接入 zine、逐页/长图导出、本机合集；
- 海报并入“一页回忆”的分享版式，不再单列一级形态；
- 立体记忆作为查看效果，不另建上传器。

### P2：真实活动空间

- 接 UNSEEN 账号、邀请、创建/加入空间、共同上传与权限；
- 把 360、照片归位和人工修正收进同一空间页面；
- 共同记忆与活动 zine 只在活动上下文出现。

### P3：空间引擎

- 单图先用低成本 2.5D / 粒子作为即时结果；
- 同场景多图接 World Labs；受控视频接真实 3DGS SceneWorker；
- 统一展示 `实拍 / 重建 / AI 补全 / 生成` 四级真实性；
- 生成任务进入“我的 → 处理中”，具备失败、取消和重试。

### P4：社区与公开发布

- 先接可审核的公开空间/作品供给，再决定推荐、关注、评论和收藏；
- 没有真实内容供给与治理合同前，“看看”继续是精选示例，不伪装成社区已成立。

## 7. 明确暂缓

- 支付、套餐、创作者身份体系；
- 全量社交关系、评论和推荐算法；
- HEIC / Live Photo / Spatial Video 的完整原件管线；
- 长视频全域重建；
- 把本机回见合集伪装成已经同步到 UNSEEN 云端。

## 8. 分支与合并规则

- 当前独立分支：`codex/unseen-3.0`；
- 本轮只新增样机、样机样式/脚本、预览路由、计划与针对样机的测试；
- 不合并其他功能分支，不改线上默认入口，不发布；
- 队友确认设计后，再从现有可用提交逐项接入，避免一次性大合并后无法判断问题来自 UI 还是功能。

## 9. P0 接入结果（2026-09-04）

独立 worktree 分支 `codex/unseen-demo-live` 已接通：

- 单图上传或内置例图；上传图在本机缩至最长边 1800px 后用于体验；
- MiniMax 读取原图、返回可见事实并只问一句；无法可靠看图时明确显示备用问题；
- 文字回答，或由用户明确开始/停止的单轮语音转写；转写结果可以编辑；
- 可选的 MiniMax 问题朗读，不影响文字主链；
- 一页回忆保留用户原话，并保存到 IndexedDB；
- “我的 → 记忆”真实列出、刷新后重开；
- 原照片层上的即时粒子效果，可随时关闭并返回原照片。

仍未接入：活动共创、账号、云同步、分享、真实 3D 重建、AI 补全、支付。它们继续以“功能示意 / 尚未接入”出现，不创建虚假任务或进度。
