# UI v4 · B「共光·灵光」逐页施工规格（主脑 2026-08-16）

依赖：基建块（图标系统/胶囊按钮/icon-tile/badge-dot/skeleton/motion/progressRing）已就位。
所有页面共同要求：文案与 action ID 不改语义（合同铁律）；每页至多一个主 CTA；页面进场 180ms 淡升；骨架屏替代所有「正在加载…」大字；safe-area 兜底；reduced-motion 全关动效。
原型基准：方案 Artifact 的 B 段三框 + 组件样本条。

## 块 2 · 首页与入口页

### P01 首页
- 删旧 hero 文字段与三卡的重复叙事（审计 B1）：页面 = 顶部品牌区 + （登录态）「继续：我的空间」进度环卡 + 三张导航卡 + 轻量邀请链接行。DOM 顺序与视觉一致，焦点顺序自然。
- 「继续」卡：progressRing(已回现场, 总数) + 空间名 + 状态语，halo-spot 允许用在此卡背后（全页唯一光晕）。未登录不渲染。
- 三导航卡：icon-tile + 标题 + 副文案 + chevron-right，radius 28，press 态。
- 旧 hero-frame 大图撤下（信息价值低、占首屏）；wedding-light 素材留给 /open 邀请落地页。
- 底部邀请行保留 text-link 形态，前面加 link 图标。

### /discover 逛逛空间
- 精选空间卡改**封面卡**：封面图（配置文件新增 cover 字段，模板空间用 assets 里的种子图路径或远端 URL，缺省显示渐变占位）+ 空间名 + 一句话简介 + 「模板空间」chip。
- 卡下「更多公开空间即将开放」改成空态组件（icon + 一句话），不再是孤行小字。
- 修 D2：featured-spaces.js 里模板空间标题统一成与 /open 落地一致的名字（读配置现值，以 /open 落地页展示名为准）。

### /start-upload 传照片
- 两卡结构不变，icon-tile 化（link / upload 图标）；下半屏空旷问题靠内容自然高度 + 页脚解决，不硬填。

### /open 粘贴邀请
- 装饰圆点与文字分层（审计 B6）：装饰移到卡外背景层 z-index 之下，或直接删。
- placeholder 改「粘贴邀请链接」（审计 B7）；扫码按钮白胶囊次级。

### /open/:token 邀请落地
- 封面卡保留，eyebrow 压图加底部 scrim 渐变（审计 B4）；主 CTA 用基建新胶囊（渐变自动回 token 色值，修 B5）。

### /login
- 结构不变，输入/按钮吃基建新规格；副文案「空间主人和成员从这里进入我的空间」保留。

### /spaces、/spaces/new
- 空间列表卡吃封面卡组件（无封面渐变占位）；创建表单吃新控件规格。

## 块 3 · 相册与照片详情

### /s/:sid/album
- eyebrow 开发黑话由块 7 文案清洗统一处理，本块先把模板改为消费 STRING-CATALOG 常量。
- 「查看」按钮删除（审计 B9）：点照片直接进详情，网格即入口。
- 相册/现场 segmented 保留但瘦身（高 44、白选中片、180ms 滑动过渡）。
- 网格：圆角瀑布流、白缝 8px、竖图占双行；per-photo 状态改 badge-dot（审计 B10），彩色语义：已回现场=渐变点、待定位=ink-subtle 点；网格上方一行分组统计「已回到现场 n · 待定位 m」。
- 滚动位置保持（审计 B11）：返回相册恢复 scroll 位置（app.js 路由层记录）。
- 纪念册入口卡吃 icon-tile（book 图标）。

### /s/:sid/photos/:pid
- 标题层重做（审计 B17）：大图优先（占屏 60%+，contain，暗色底），下方信息卡：空间名 + 「第 x 张 · 上传者 · 时间」，杀重复「照片」标题。
- 「人工已确定」等状态词映射成用户语言（块 7 终审）：本块先落「已回到现场/待定位/审核中」三态 chip。
- 主 CTA 回到现场（胶囊）；举报收进「⋯」菜单（审计 B19），确认对话框不变。
- 返回链接文案「返回相册」，保留恢复滚动语义。

## 块 4 · 现场 360（最重）

### /s/:sid/scene
- 全屏沉浸：viewer 区 edge-to-edge（突破 .page 容器），高度 = 100dvh - header；背景 viewer-canvas，全景画布满区（cover），杀死黑条（审计 B12）。
- 控件全部收进**底部玻璃操作带**（backdrop-blur + viewer-surface 半透明）：左「返回相册」图标钮 / 中已定位照片胶片条（横滚，当前高亮）/ 右罗盘钮（单钮开方向盘，替代前后左右四字键，审计 B14）。
- 方向与位置语（「面向东南 · 附近 3 张照片」）为 HUD 单行，polite aria-live 保留（合同§8 全部可访问性要求不降级：skip 链接、方向控制组、非视觉照片列表、双入口返回、WebGL 失败降级）。
- toast 不常驻（审计 B15）：出现 3s 自动退，不遮 HUD。
- placement-editor 同步吃玻璃控件与胶片条组件，交互流程不改。

## 块 7 · 终审清洗
- 文案清洗表（黑话→用户语言）：本机可操作样本→「示例空间」、人工已确定→「已由主人确认」、其余以 STRING-CATALOG 为准新增常量。
- 块 4 遗留复核：①390px 首页 h1「打开你的共同空间」断词换行（44px 字号过大，降 36 或收文案）；②viewer 不可用降级态只有「重新加载」，合同 §8 的 2D 方向列表在失败态是否要补（历史行为如此，语义未降级，需产品判断）；③Track 4 自带顶部三按钮在 390px 换行占高（冻结包不可改，只能接受或总控 RFC）。

- 无障碍复检：focus 可见性（burgundy outline 在新胶囊上仍达标）、对比表复核（合同§7 evidence 表逐项）、200% zoom、320px。
