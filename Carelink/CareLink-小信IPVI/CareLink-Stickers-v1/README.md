## 建议规格
常规主贴最长边约50–55mm；长文案款约60–65mm。尺寸含白边，最终依矢量重绘后实测。
哑面白色合成纸或薄膜类不干胶，优先试可移除胶，约2mm白边、至少3mm间距，异形半断、整张离型底纸保留。
这不是材料性能认证：是否可移除、耐擦拭或适合杯身，需要厂家样片与实际表面打样确认。

## 制作边界
当前为设计方案与拼版视觉稿。PNG 中的白边不是独立矢量刀线。
正式生产需逐枚重绘、分离贴片、建立独立闭合刀线、补出血并按实际尺寸重新拼版。
本包没有独立透明单枚图、AI/CDR 逐枚矢量稿或可直接驱动切割机的刀模。
A5 PDF 可按实际尺寸查看布局与风格，文件名明确标为视觉校样，不作为刀模文件。
字体、文字及角色细节在印前统一校对；生成式图像中的轻微变体以原始已选角色为准。
