# 原型 SCEN → P1 测试映射

原型共 19 个场景。以下只验证可独立执行的业务逻辑；UI、OCR/报告识别、真实模型、设备、真实通知均不是这些测试的证明范围。

| SCEN id | P1 自动测试 | 尚未验证的场景部分 |
|---|---|---|
| med | UTTER med；同一时段提醒、原声优先、确认和库存 | 真机播放与手机回执界面 |
| mem | UTTER mem；照片带原音、红点、记忆人物抽取结果保留 | 照片上传、族谱界面与真实人物消歧 |
| mix | UTTER mix 同时产生 memory/diet/discomfort | 真实模型抽取 |
| report | child/elder 投影与审核建议待听队列 | 拍照、报告 OCR、报告解读本体不在本轮 |
| emg | UTTER emg；每个紧急词；模型挂起仍立即调用假传输接口 | 真实推送和到达时延 |
| timeout | 一次超时通知、不重复催促、晚到确认 | 实际云定时器/断电场景 |
| offline | 上下行离线队列、补发顺序、ACK/重试 | 断网设备、持久化与重启恢复 |
| unclear | UTTER blur；非法模型响应待确认、保留音频 | 真人含糊音频的 ASR |
| merge | 两条用药合并一次提醒、共同确认 | 连续播放听感 |
| tip | 已审核建议投影和待听 | 实际医学知识库审核和播放 |
| praise | 表扬作为待听建议、不向老人暴露分数 | 手机依从性页面 |
| guard | UTTER ask、输入/输出调药和诊断专测 | 真实模型红队评测 |
| dh | 无原声时 synthetic 与合成标记 | TTS 服务与数字人 |
| scan | draft 不生效、子女核对 active、服药扣余量 | 药盒 OCR、照片预览 |
| refill | 补同一计划库存且幂等 | 真实药盒去重识别 |
| cheat | 火锅/月饼意愿不记已吃，不输出未审核医疗承诺 | “交换条件”医学内容需另行审核，未照搬 |
| batch | 多个核对后的计划可保存 | 整袋 OCR、UI 一键核对，不宣称已实现识别 |
| me2 | 人物/家庭隔离，同名 ID 不串档 | 注射部位轮换、体重趋势不属于 P1 指定数据模型，未实现 |
| week | 服药率、饮食和不适聚合，老人无分数 | 真实周报任务、复查时间和临床建议 |

12 个 UTTER 均按原文保存为测试夹具；其中姓名只出现于引用原型的测试语句，不是产品初始化数据。没有复制原型 base64 图片、假家庭或假病历。
